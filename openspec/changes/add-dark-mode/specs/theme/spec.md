## ADDED Requirements

### Requirement: 다크 모드 켜고 끄기
시스템은 기본으로 라이트 테마를 보여야 하며, 내 정보 > 설정의 `다크 모드` 스위치로 다크 테마를 켜고 끌 수 있어야 한다(SHALL). 선택은 그 기기에 남아야 한다(SHALL).

#### Scenario: 처음 연 기기
- **WHEN** 다크 모드를 고른 적 없는 기기에서 앱을 연다
- **THEN** 라이트 테마로 보인다

#### Scenario: 다크 모드를 켠다
- **WHEN** 사용자가 설정에서 `다크 모드`를 켠다
- **THEN** 화면이 즉시 어두운 토큰으로 바뀌고 스위치가 켜짐으로 보인다
- **AND** 상태 표시줄 색이 어두운 상단 바 색으로 바뀐다

#### Scenario: 다시 연다
- **WHEN** 다크 모드를 켠 기기에서 앱을 다시 연다
- **THEN** 앱이 뜨기 전부터 어두운 테마로 그려진다
- **AND** 끄면 라이트로 돌아가고 다시 열어도 라이트다

### Requirement: 다크 테마의 읽기 대비
다크 테마는 라벨 글자와 강조 글자를 각자의 바탕 위 4.5:1 이상으로 보여야 한다(SHALL). 선택된 칩처럼 본문색을 바탕으로 쓰는 요소는 글자가 바탕과 반대 명도로 바뀌어야 한다(SHALL).

#### Scenario: 선택된 종류 칩
- **WHEN** 다크 테마에서 장소 추가의 종류를 고른다
- **THEN** 고른 칩은 밝은 바탕에 어두운 글자로 보인다

### Requirement: 우리나라 지도는 흰 땅
방문 통계와 여행 목록 배너의 우리나라 지도 땅은 다크 테마에서도 흰색이어야 한다(SHALL).
