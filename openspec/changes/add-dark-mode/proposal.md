# 다크 모드 추가

밤에 여행지에서 일정을 볼 때 흰 화면이 눈부시다. 사용자가 내 정보 > 설정에서 다크 모드를 켜고 끌 수 있게 한다(2026-10-06 사용자 요청).

## 범위

- 기본은 라이트. 설정의 `다크 모드` 스위치로 즉시 전환하고 선택은 기기에 남긴다.
- 색은 비교 시안 중 A '그래파이트'(사용자 선택). 라벨 색의 뜻은 유지하고 밝기만 옮긴다.
- 방문 통계의 우리나라 지도 땅은 다크에서도 흰색(사용자 결정).
- 앱이 뜨기 전에 테마를 적용해 흰 화면 번쩍임을 막는다. 상태 표시줄 색(`theme-color`)도 함께 바꾼다.

## 범위 밖

- 기기 설정(prefers-color-scheme) 따라가기, 계정 간 동기화.
- 카카오 지도 타일·사용법 캡처·그림 자산의 어두운 판.
