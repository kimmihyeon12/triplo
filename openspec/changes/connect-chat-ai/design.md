# 설계

브라우저의 로컬 명령 처리가 답하지 못하면 EdgeChatProvider → AuthStore.callFunction(ai-chat) → 인증된 서버 → Gemini 순서로 호출한다. 입력은 현재 질문, 최근 대화 최대 10개, 여행의 지역·일차·장소 이름 요약이며 전체 기록·경비·좌표를 보내지 않는다. 모델 키와 시스템 프롬프트는 서버에만 둔다.

서버는 로그인 토큰을 검증하고 길이·배열 크기·일차 범위를 검사한다. 모델 호출 시간은 최대 45초다. 응답은 서버와 앱에서 같은 순수 계약 검증기로 확인한다. 장소의 이름·day·kind만 받고 주소·좌표·검증 여부·edit·모델 링크는 버린다. 실제 위치는 기존 장소 검색으로 검증한다. 영업정보는 참고 유형과 앱이 만든 지도 검색 링크를 요구한다.

취소 신호는 Supabase Functions SDK로 전달한다. 오류는 인증·한도·시간 초과·서버 실패로 안내하며 고정 응답으로 대체하지 않는다. 기존 클라이언트 대화 한도와 모델 제공자의 quota 오류를 사용한다. 서버의 사용자별 영구 사용량 집계는 이번 변경에 포함하지 않는다.
