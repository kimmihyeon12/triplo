# Design

2026-10-06 색상 후속 결정: 사용자 재선택에 따라 목록·상세 AI 챗봇 진입 버튼을 기존 #16181D로 복원한다. Hover는 #2B2F38, 글자는 흰색이며 앱의 나머지 색상과 밤이 외형·배치는 유지한다.

2026-10-06 최종 외형 결정: 후속 요청에 따라 기존 갈색 이마 줄무늬 있는 밤이로 복원한다. 진입 버튼은 companion-bami-peeking-v1.png, 대화 전신은 companion-bami-v1.png를 사용한다. 얼굴의 살구색·크림색 볼·둥근 고동색 외곽선·콩눈·파란 스카프와 전신의 꼬리/몸 무늬는 유지한다. 버튼80×48px·얼굴64×38px·대화72px/48px 및 챗봇 진입 버튼 외 색상은 유지한다.

## Decisions
2026-10-06 후속 요청: 밤이와 버튼을 줄인 뒤 폭60px는 너무 좁다는 피드백을 반영해 폭만80px로 넓힌다. 버튼80×48px·글자12px, 이미지64×38px, 상단 겹침7px를 최종 규격으로 사용한다. 기존112×44px·이미지96×58px 규격은 폐기한다.
승인된 시안에서 버튼·문자·배경을 제거한 얼굴/스카프/두 앞발 투명 PNG를 사용한다. HTML 버튼과 글자는 유지하여 접근성과 원래 색상을 보존한다. 버튼은 높이48px/너비80px, 이미지 상자는64×38px로 중앙 정렬하고 버튼 위쪽에 배치한다. 이미지 아래쪽은 버튼 상단에7px 겹쳐 앞발이 걸린 것처럼 보이게 한다. 글자는 버튼 중앙에 있어 가리지 않는다. 진입 위치와 안전 영역을 유지한다.

## Scope
전체 대화72px·시트48px 전신은 갈색 이마 줄무늬 있는 v1로 갱신하며 서버 지침은 바꾸지 않는다. 버튼 배경 #16181D·hover #2B2F38·흰 글자를 사용한다. 기존 전신 규칙은 대화 화면에 계속 적용하고 새 이미지의 얼굴/앞발만 진입 버튼에 사용한다.

## Verification
기존 E2E에서 이미지 경로, 색상, 실제 버튼 크기, 이미지와 버튼 상단 겹침, 글자 비겹침, 상세 하단 바 비겹침 및 채팅 열기를 확인한다. 사용법 capture를 재생성하고 운영 build/lint/시각 캡처를 확인한다.
