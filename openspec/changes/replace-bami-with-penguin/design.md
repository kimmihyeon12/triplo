# Design

승인된 비교 자료의 펭귄 PNG를 그대로 사용한다. 이미지 생성이나 재해석 없이 원본을 복사한다. 진입은64×48px 상자로 object-contain/object-bottom 배치하며 기존 버튼80×48px와7px 겹침을 유지한다. 전체 대화72px·상세 시트48px에도 동일 자산을 사용한다. idle/talking/found 상태는 같은 이미지를 공유한다.

밤이 대신 펭귄이라고 안내하고 AI 챗봇 제목을 사용한다. 서버는 자신을 펭귄 여행 친구로 안내한다. 숙박의 '밤' 문구와 대화 기록은 유지한다. 이전 밤이 자산은 비교 자료 보존을 위해 삭제하지 않는다.

기존 mascot E2E에서 이미지 로드·크기·색상·겹침·진입 동작을 확인한다. 사용법14장과 강조 위치를 재생성한 후 lint와 빌드를 검증한다. 원격 배포는 수행하지 않는다.
