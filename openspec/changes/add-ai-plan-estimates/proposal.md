# 자동생성 예산·요금 기준·체류시간

## Why
현재 자동생성 결과는 장소 이름과 일차만 제공한다. 사용자는 인원에 맞는 예상 비용, 요금 계산 단위, 장소에서 머무를 시간을 함께 확인하고 싶다.

## What Changes
- 생성 조건에 본인 포함 인원, 전체 기간 예산, 1인/전체 인원 기준을 추가한다.
- 장소별 원화 예상 단가 범위·기준·수량·가정과 추천 체류시간 범위·이유를 제공한다.
- 선택과 일차 변경에 따라 장소 비용 합계를 계산하고 미정 항목을 명시한다.
- 담기 시 상한을 기존 계획 금액·체류시간에 저장하고 계산 기준·AI 추정 표시를 메모에 보존한다. 실제 지출에는 기록하지 않는다.

## Capabilities
### New Capabilities
- `ai-plan-estimates`: 자동생성의 예산 조건, 추정 금액·체류시간과 저장 규칙.

## Impact
Angular 자동생성 화면·제공자·파서·저장 변환과 Supabase ai-plan 요청/응답이 확장된다. 기존 필드는 유지하며 DB 마이그레이션은 필요하지 않다. 서버와 앱 모두 배포해야 새 추정 정보가 생성된다.

## Scope
현재 장소 검증 제공자는 실제 요금을 제공하지 않으므로 생성되는 금액은 모두 AI 추정이다. 모델이 만든 URL·확인일을 공식 요금 근거로 쓰지 않는다. 별도 숙소·교통비 생성과 가계부 예산 자동 저장은 이번 범위에 포함하지 않는다. 입력 예산은 추천 조건이며 합계는 선택 장소 비용이다.
