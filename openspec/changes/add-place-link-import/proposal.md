# 지도 링크로 장소 담기

## 왜

네이버·카카오맵 웹에는 나오는데 앱의 장소 검색(카카오 개발자용 검색)에는 없는 장소가 있다. 2026-10-01 사용자 사례 '신가회전훠궈 수원역점'은 카카오 지도 SDK 검색에서 0건이었다. 지도 앱에서 찾은 곳을 이름을 기억해 두었다 다시 검색하는 수고도 크다.

## 무엇을 바꾸나

- 장소 추가 화면에 `링크로 담기`를 둔다. 네이버·카카오 지도에서 복사한 링크를 붙여 넣는다.
- 서버 함수 `resolve-place`가 링크를 한 번씩 따라가며(허용 호스트만, 최대 4번) 제공자의 장소 정보에서 이름·주소·분류·좌표를 읽는다.
- 앱은 링크 좌표 근처 카카오 검색에서 같은 곳(이름이 맞고 200m 안)을 찾으면 그 후보로, 없으면 링크의 값으로 담는다. 출처(`naver`/`kakao`)와 원본 링크를 남긴다.
- 사용법 여행 상세 장의 일정 추가 설명에 링크 담기를 넣는다.

## 범위 밖

앱을 열 때 클립보드 먼저 읽기, 숙소 화면의 링크 담기, 영업시간·사진 가져오기.
