# 큰 지도에서 주변 장소 골라 담기

## 왜

모바일에서 지도를 크게 보며 주변 장소를 골라 바로 일정에 담고 싶다(2026-10-01 사용자 요청). 지금 지도는 여행 상세의 작은 지도뿐이고, 담으려면 이름으로 검색해야 한다.

## 무엇을 바꾸나

- 여행 상세 지도의 `크게 보고 담기`로 `/trips/:id/map`을 연다. 지도가 화면을 다 쓴다.
- `맛집·카페·관광·숙소`를 누르면 보이는 범위의 카카오 장소를 핀으로 보인다. 지도를 옮기면 `이 지역에서 다시 찾기`.
- 핀 → 정보판 → 담을 날 → `담기`. 숙소는 숙소 추가 화면으로 넘긴다.
- 사용법에 '지도에서 담기' 장을 더한다(14장).

## 범위 밖

지도 기본 장소 누르기(카카오 SDK 미지원), 아무 지점 길게 눌러 담기, 핀 묶음.
