# 설계

추가 승인된 말풍선 수정: 사용자·구름이 메시지는 18px 모서리로 부드럽게 표시한다. 구름이 답변과 응답 대기에만 8px 정사각형을 45도 회전한 왼쪽 꼬리를 둔다. 꼬리는 기존 아바타 간격 안에서 약 6px 돌출되며 말풍선과 같은 배경·테두리색을 사용한다. 긴 단어는 줄바꿈하여 모바일 너비를 유지한다. 공통 ChatThread의 CSS로 전체 채팅과 상세 시트에 동일 적용한다.

기존 CompanionFace 공개 컴포넌트를 유지해 여행 기능의 의존 경계를 바꾸지 않는다. idle은 졸림, talking/found는 승인된 작은 미소를 사용한다. 응답 대기 중에는 talking을 표시한다. 이미지의 전체 캔버스를 object-contain으로 표시하고 위치 이동·확대·잘림을 제거한다.

목록 링크와 상세 버튼은 기존 경로·클릭 핸들러·안전 영역을 유지한다. 높이 44px, 왼쪽 여백 52px, 오른쪽 14px, 글자 13px로 표시하고 56px 캐릭터를 왼쪽 아래 1px에 절대 배치한다. 별도 대화 아이콘을 넣지 않는다.

최종 독립 미리보기와 통합 적용 기록은 보존한다. public/brand의 캐릭터는 선택한 두 장만 남긴다. 이전 생성 원본이 있는 사용자 .codex 디렉터리는 정리 대상이 아니다.

검증은 별도 test 구성 4300 포트의 기존 채팅 E2E, 프로덕션 빌드, 경계 검사, 데스크톱·360px 캡처로 한다.
