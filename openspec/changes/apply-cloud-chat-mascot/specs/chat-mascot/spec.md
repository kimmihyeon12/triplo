## ADDED Requirements

### Requirement: 부드러운 메시지 말풍선
앱은 사용자·구름이 메시지를 18px 모서리로 표시하고 구름이 답변·응답 대기에는 아바타 쪽의 작은 꼬리를 표시해야 한다(SHALL).

#### Scenario: 좁은 화면의 대화
- **WHEN** 360px 화면에서 답변 또는 응답 대기 말풍선을 표시한다
- **THEN** 꼬리가 아바타와 겹치지 않고 긴 텍스트가 가로 넘침 없이 줄바꿈된다

### Requirement: 알아볼 수 있는 AI 채팅 진입점
앱은 여행 목록과 상세에 파란 ‘AI 채팅’ 진입점을 표시해야 한다(SHALL). 높이는 44px 이상이어야 하며, 졸린 구름이 전신과 텍스트를 함께 표시하고 중복되는 말풍선 아이콘은 표시하지 않아야 한다.

#### Scenario: 채팅 열기
- **WHEN** 사용자가 목록 또는 상세의 AI 채팅 진입점을 누른다
- **THEN** 기존 전체 채팅 또는 여행 대화 시트가 열리고 다른 일정 동작을 가리지 않는다

### Requirement: 잘리지 않는 구름이
앱은 승인된 작은 미소·졸림 이미지의 전신을 크롭 없이 표시해야 한다(SHALL). 대화 아바타는 48px, 헤더는 56px로 표시한다.

#### Scenario: 답변과 대기 표시
- **WHEN** 구름이가 답하거나 응답을 준비한다
- **THEN** 작은 미소를 표시하고, 진입 버튼에는 졸림을 표시한다

### Requirement: 미사용 시안 정리
선택한 두 이미지와 최종 미리보기·통합 기록은 유지하고 미채택 캐릭터와 개별 생성 기록을 제거해야 한다(SHALL).

#### Scenario: 정리 후 참조
- **WHEN** 앱과 보존된 최종 미리보기를 연다
- **THEN** 모든 캐릭터 이미지가 로드되고 삭제된 시안을 참조하지 않는다
