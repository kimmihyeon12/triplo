# 구름이 챗봇 시안 적용

## Why
흰 원형 버튼은 AI 채팅임을 알기 어렵고 기존 얼굴 크롭은 몸통이 잘린 것처럼 보인다. 사용자가 승인한 최종 시안을 현재 앱에 적용하고 미채택 이미지와 생성 기록을 정리한다.

## What Changes
- 채팅 입력창의 과도한 라운드를 줄여 공통 control 반경 10px를 사용한다.
- 추가 승인: 메시지 모서리를 18px로 통일하고 구름이 답변·응답 대기에 작은 왼쪽 꼬리를 붙인다.
- 구름이 작은 미소·졸림 두 이미지로 캐릭터를 교체한다.
- 목록·상세의 진입 버튼은 높이 44px, 파란 배경, 56px 구름이와 ‘AI 채팅’ 문구로 표시한다. 별도 말풍선 아이콘은 넣지 않는다.
- 대화 48px·헤더 56px 전신을 크롭 없이 표시한다.
- 미사용 이미지와 개별 생성 MD, 이를 참조하는 낡은 비교 시안을 제거한다.

## Impact
채팅 표시와 진입점만 변경한다. 추천·검증·저장 및 기존 사용자 작업은 유지한다.
