## ADDED Requirements

### Requirement: AI 호출 기록
시스템은 서버 함수가 Gemini를 부를 때마다 기능·모델·성공 여부·입력/출력 토큰을 남겨야 한다(SHALL). 기록에 실패해도 사용자 요청을 막아서는 안 된다(SHALL NOT).

#### Scenario: 실패한 호출도 센다
- **WHEN** Gemini가 오류로 답하거나 시간 초과가 난다
- **THEN** 성공 여부 거짓, 토큰 0으로 한 줄 남는다

### Requirement: 관리자 사용량 화면
관리자는 무료 한도 대비 사용률과 이번 달 추정 비용을 볼 수 있어야 한다(SHALL). 일반 사용자는 기록과 집계를 볼 수 없어야 한다(SHALL NOT).

#### Scenario: 한도 경고
- **WHEN** 오늘 Gemini 호출이 하루 한도의 80% 이상이다
- **THEN** 막대를 경고색으로 보이고 "80% 넘음"과 비율 숫자를 함께 적는다

#### Scenario: 단가 없는 모델
- **WHEN** 이번 달 기록에 단가표에 없는 모델이 있다
- **THEN** 그 모델은 "단가 미등록"으로 보이고 합계에서 빼며 몇 회를 뺐는지 알린다

#### Scenario: 응답 형식 오류
- **WHEN** 집계 응답 형식이 깨졌다
- **THEN** 숫자를 지어내지 않고 불러오지 못했다고 알린다
