## 13. 대화형 여행 탐색 챗봇

2026-09-17 기획 완료, 구현 미착수. 설계는 [설계 문서](../../../docs/superpowers/specs/2026-09-17-travel-chat-design.md)와 기획안 35절을 따른다.

2026-09-17 사용자 결정으로 작업 순서를 정했다. **13-A 화면 → 4절 Supabase 저장 → 13-B 서버 연결 → 8절 초대·공유** 순이다. 화면을 먼저 만드는 이유는 시트 높이·확인 카드 가독성·칩 개수처럼 그려 봐야 아는 것들이 기획에 남아 있고, 서버를 다 만든 뒤 배치를 고치면 되돌리는 비용이 크기 때문이다. 12절의 친구 초대·가계부도 같은 방식(DB 없이 화면 먼저)으로 진행했다.

호출 제한과 대화 저장은 서버를 요구하므로 13-B로 미룬다. 혼자 또는 친구 몇 명이 쓰는 동안은 기기 저장으로 충분하다.
