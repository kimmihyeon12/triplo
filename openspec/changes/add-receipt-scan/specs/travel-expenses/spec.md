## ADDED Requirements

### Requirement: 정산 내용 복사
시스템은 정산 현황의 남은 정산을 메신저에 붙여 넣을 수 있는 글로 SHALL 복사한다.

#### Scenario: 남은 정산이 있을 때 복사
- **WHEN** 사용자가 정산 현황에서 정산 내용 복사를 누른다
- **THEN** `[여행 이름] 정산`, 개인 지출을 뺀 공동 지출 합계, `보낼 사람 → 받을 사람 금액` 줄을 클립보드에 넣고 복사 결과를 알린다

#### Scenario: 클립보드를 쓸 수 없음
- **WHEN** 브라우저가 클립보드 쓰기를 거부한다
- **THEN** 복사하지 못했다고 알리고 정산 기록은 바꾸지 않는다

### Requirement: 사진으로 지출 입력
시스템은 영수증·결제 캡처 사진에서 읽은 항목을 사용자가 확인한 뒤에만 지출로 SHALL 저장한다.

#### Scenario: 여러 항목 인식
- **WHEN** 사용자가 사진을 올려 읽기를 누른다
- **THEN** 로그인한 사용자에 한해 서버가 항목·금액·날짜·분류 후보를 돌려주고, 앱은 검증을 통과한 후보를 모두 체크된 목록으로 보여 준다

#### Scenario: 형광펜으로 범위 지정
- **WHEN** 사용자가 사진 위에 형광펜을 칠하고 읽기를 누른다
- **THEN** 칠한 줄만 후보로 읽도록 요청한다

#### Scenario: 확인 후 저장
- **WHEN** 사용자가 후보를 고치고 일부만 체크해 저장한다
- **THEN** 체크한 항목만 지출로 저장하며 각 지출은 결제자·분담 기본값과 `사진에서 읽음` 메모를 갖는다

#### Scenario: 한 건으로 합치기
- **WHEN** 사용자가 한 건으로 합치기를 켜고 저장한다
- **THEN** 체크한 금액의 합을 지출 한 건으로 저장한다

#### Scenario: 읽을 항목이 없음
- **WHEN** 모델 응답에 검증을 통과한 항목이 없다
- **THEN** 아무것도 저장하지 않고 다른 사진이나 직접 입력을 안내한다

#### Scenario: 사진 비공개
- **WHEN** 인식 요청을 처리한다
- **THEN** 사진을 앱 저장소나 서버에 남기지 않는다
