## ADDED Requirements

### Requirement: 명확한 채팅 결정 동작
시스템은 변경 카드를 답변 아래 전체 대화 너비로 표시하고, 왼쪽 ‘그대로 두기’와 오른쪽 주 동작 ‘변경 적용’을 높이 44px 이상으로 제공해야 한다(SHALL).

#### Scenario: 변경 적용 또는 보류
- **WHEN** 사용자가 변경 미리보기를 확인한다
- **THEN** 적용 전에는 저장 값이 바뀌지 않는다
- **AND** 그대로 두기는 변경 없이 카드를 접고 변경 적용은 기존 확인 동작을 실행한다
- **AND** 적용 뒤에는 반영 상태와 되돌리기를 표시한다

### Requirement: 일관된 채팅 컨트롤
전체 채팅과 상세 시트는 공통 메시지 간격과 입력·전송·추천 질문 스타일을 사용해야 한다(SHALL).

#### Scenario: 모바일과 데스크톱
- **WHEN** 360px 또는 1280px에서 채팅을 사용한다
- **THEN** 가로 페이지 넘침 없이 카드 내용을 읽고 결정할 수 있다
- **AND** 입력과 전송 컨트롤은 10px 반경을 사용한다

### Requirement: 가벼운 완료 및 중지 안내
시스템은 저장 완료를 구름이 대화 메시지로, 응답 중지를 대기 말풍선 옆 컨트롤로 제공해야 한다(SHALL).

#### Scenario: 저장 완료
- **WHEN** 여행 저장이 완료된다
- **THEN** ‘여행에 담았어요’ 대화 메시지와 ‘여행 보기’ 이동 동작을 제공하며 별도 완료 바는 표시하지 않는다

#### Scenario: 추천 질문과 스크롤 여백
- **WHEN** 대화를 스크롤하거나 추천 질문을 탐색한다
- **THEN** 추천 질문은 연한 파란색 알약 모양이다
- **AND** 메시지 스크롤 영역 밖 위아래 6px, 내부 패딩 8px, 메시지 사이 12px, 추천 질문 줄 위아래 8px 공간을 유지한다

#### Scenario: 응답 중지
- **WHEN** 응답을 기다리는 사용자가 ‘응답 중지’를 누른다
- **THEN** 기존 요청 취소가 실행되고 대기 표시가 사라진다
- **AND** 이동 및 중지 컨트롤은 높이 44px 이상이다

### Requirement: 작은 시각 크기와 충분한 클릭 영역
결정·되돌리기 버튼과 추천 질문은 시각 높이 32px·글자 12px로 표시하고 클릭 영역은 44px 높이를 유지해야 한다(SHALL). 이전 결정 버튼 44px 높이는 클릭 영역 기준으로 해석한다.

#### Scenario: 작은 컨트롤
- **WHEN** 사용자가 확인 카드 또는 추천 질문을 본다
- **THEN** 적용 버튼은 불필요한 고정 최소 폭 없이 내용에 맞고 추천 질문은 알약 모양이다
- **AND** 스크롤 및 추천 질문 상하 여백은 유지한다

#### Scenario: 텍스트 말풍선 내부 여백
- **WHEN** 사용자 또는 구름이 텍스트 메시지를 표시한다
- **THEN** 상하 패딩은 각각 6px이며 기존 행간과 좌우 여백을 유지한다

### Requirement: 중복 없는 채팅 헤더
전체 채팅과 상세 시트 헤더는 48px 구름이와 제목·보조 문구를 표시해야 한다(SHALL).

#### Scenario: 채팅에서 구름이 표시
- **WHEN** 전체 채팅 또는 상세 시트를 연다
- **THEN** 헤더에 구름이를 한 번만 표시하고 답변·대기·빈 화면에는 구름이를 표시하지 않는다

### Requirement: 새 대화
전체 채팅과 상세 시트 상단은 새 대화 버튼을 제공해야 한다(SHALL).

#### Scenario: 새 대화 시작
- **WHEN** 새 대화를 누른다
- **THEN** 대기 요청을 취소하고 대화 기록·입력·미리보기·되돌리기 상태를 초기화한다
- **AND** 저장된 여행은 유지하며 전체 채팅의 이전 여행 연결만 해제한다
- **AND** 상세 채팅은 현재 여행을 대상으로 유지한다

#### Scenario: 여러 줄 메시지 행간
- **WHEN** 사용자 또는 구름이 텍스트 말풍선을 표시한다
- **THEN** 본문 글자는 14px이고 줄 높이는 20px다

### Requirement: 읽기와 조작 밀도의 균형
최신 기준은 이전 본문 20px 행간·6px 패딩·12px 버튼 글자를 대체한다. 본문은 14px·줄 높이 22px·상하 패딩 8px이며 결정 버튼은 32px·13px, 추천 질문은 13px로 표시해야 한다(SHALL).

#### Scenario: 로컬 변경 미리보기
- **WHEN** 로컬 명령의 확인 카드를 표시한다
- **THEN** 변경되지 않은 여행 제목/날짜·예산·지출 행을 생략한다
- **AND** 변경 항목의 전후와 삭제할 항목은 확인 가능하다
- **AND** 실제 적용 검증은 전체 원본 상태를 기준으로 한다
