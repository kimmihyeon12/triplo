# 채팅 레이아웃 정리

최신 후속 요청: 저장 완료는 상태 행 대신 대화로 안내하고 추천 질문 알약 모양을 복원한다. 스크롤 가장자리와 추천 질문 줄의 상하 여백을 확보한다.

확인 카드가 아바타 옆 좁은 폭에 갇히고 두 결정 버튼의 시각적 비중이 비슷해 답답하다. 카드를 답변 아래로 분리하고 결정 버튼의 위계, 메시지 간격, 추천 질문과 전송 컨트롤을 정리한다. 저장 및 AI 동작은 유지한다.

후속 범위: 여행 저장 완료 안내와 응답 중지 동작을 같은 가벼운 채팅 스타일로 정리한다.

최신 후속: 결정·되돌리기 버튼과 추천 질문의 시각 크기를 줄인다. 저장·취소 동작은 유지한다.

후속 요청: 대화 여백을 줄여 한 화면에서 더 많은 메시지를 읽도록 한다.

후속 범위: 사용자·구름이 말풍선 내부의 상하 여백을 줄인다.

후속 범위: 전체 채팅과 상세 시트에서 답변 아바타와 중복되는 헤더 구름이 이미지를 제거한다.

최종 요청은 반대로 헤더 구름이만 유지하는 것이다. 대화·대기·빈 화면의 중복 캐릭터를 제거한다.

추가 기능: 두 채팅 헤더에서 새 대화를 시작할 수 있다. 여행 데이터는 보존하고 현재 대화만 초기화한다.

행간 후속 요청: 사용자·구름이 말풍선의 줄 높이를 줄여 읽기 밀도를 높인다.

최신 범위: 읽는 영역의 여유를 복원하고 조작부는 작은 크기를 유지한다. 로컬 미리보기의 바뀌지 않은 여행·예산·지출 행을 제거한다.
