# 설계

최신 결정은 아래 완료 행·추천 컨트롤 형태를 대체한다. commit 성공 뒤 Store가 system 메시지와 여행 링크를 기록하며 AI 요청 대화에서는 제외한다. UI는 구름이 답변으로 표시하고 RouterLink로 이동한다. 별도 완료 바와 페이지 상태를 제거한다. 추천 질문은 rounded-pill·accent-tint로 복원한다. scroller 외부 상하 12px와 추천 줄 상하 12px 패딩으로 스크롤 위치와 무관한 여백을 확보한다.

공통 ChatThread와 ChatConfirmCard의 템플릿만 변경한다. 구름이 48px, 메시지 18px 반경과 꼬리, 입력창 10px 반경은 유지한다. 확인 카드는 아바타 행 밖의 전체 너비에 두고 중성 1px 테두리·16px 여백을 사용한다. 구분선 아래 보조 동작은 왼쪽, 주 동작은 오른쪽이며 모두 44px 높이다. ‘반영하기’를 ‘변경 적용’으로 명확히 한다. 메시지 간격은 24px, 추천 질문은 중성 테두리·10px 반경·44px 높이, 전송은 10px 반경으로 통일한다.

4300 test 앱을 사용해 모바일 360px와 데스크톱 1280px에서 확인한다. 변경 전 저장 방지, 적용, 그대로 두기, 되돌리기, 가로 넘침, 전체 채팅과 상세 시트를 검증한다.

완료 안내는 기존 하단 위치를 유지하되 녹색 전체 배경과 채움 버튼 대신 중성 표면·체크·상태 문구·텍스트 이동 버튼을 사용한다. 내부 너비는 대화와 같은 max-w-160이다. 대기 중 취소는 말풍선 오른쪽의 작은 중지 표시와 ‘응답 중지’로 바꾸며 44px 클릭 높이를 유지한다. 동작과 저장 로직은 변경하지 않는다.

최신 크기 조정은 이전 시각 높이 44px를 대체한다. 확인 카드 동작은 공통 btn--sm(32px)과 12px 텍스트를 사용하고 적용 최소 폭은 제거한다. 추천 질문도 32px·12px 텍스트·좌우 12px로 줄인다. 기존 공통 버튼 및 추천 질문의 투명 ::after 영역은 44px이며 상하 여백 안에 머문다.

최신 간격: 메시지 gap 12px, 답변과 카드 gap 8px, 스크롤 외부 my 6px, 내부 py 8px, 추천·입력 래퍼 py 8px. 사용자 말풍선 px 14px·py 10px. 기존 12px 외부 여백·24px 메시지 간격을 대체한다.

말풍선 내부 최신 조정: 두 텍스트 말풍선의 py-2.5를 py-1.5로 교체한다(10→6px). 좌우 여백·행간·대기 표시는 유지한다.

헤더 최신 조정: 두 채팅 헤더의 CompanionFace와 미사용 import를 제거한다. 제목과 보조 문구·닫기는 유지한다. 전체 헤더는 py-3, 상세 헤더는 pt-1/pb-2로 이미지가 차지하던 공간을 줄인다. 대화·대기·빈 상태·진입 버튼의 캐릭터는 유지한다.

최종 배치: 두 헤더에 CompanionFace 48px를 복원한다. ChatThread에서 캐릭터·moodOf·관련 import를 제거하고 텍스트를 대화 왼쪽에 정렬한다. 아바타를 가리키던 말풍선 꼬리도 제거한다. 대기 점·응답 중지와 빈 화면 안내는 유지한다. 직전 헤더 제거 결정을 대체한다.

새 대화는 기존 store.reset을 사용하고 입력·적용 메시지·dismiss 상태를 함께 초기화한다. 전체 채팅은 여행별 및 목록 대화 기록을 비우고 대상 여행을 해제하며 상세는 현재 여행을 유지한다. 요청을 취소하고 이전 요청 finally가 새 요청의 pending을 덮지 않게 컨트롤러를 확인한다. 서버 사용량 제한은 변경하지 않는다.

본문 행간 최신 변경: 두 텍스트 말풍선만 leading-relaxed에서 leading-5(20px)로 바꾼다. 14px 글자와 패딩은 유지한다.

최신 구현: 말풍선 line-height 22px/py 8px, 확인 버튼 글자 13px/높이 32px, 추천 질문 글자 13px. local-change 미리보기에서 여행 제목/날짜와 예산은 변경 시만 표시하며 지출은 id별 원본 비교로 변경된 항목만 표시한다. 장소/숙소 변경 필터와 전체 snapshot 적용 검증은 유지한다. before만 있는 삭제도 비교 카드에 표시한다.
