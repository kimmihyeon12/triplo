# Design

## Context
2026-10-06 사용자가 큰 얼굴·둥근 고동색 선을 다듬은 밤이의 1번 콩눈을 선택했다. 기존 구름이 진입 버튼은 56px, 채팅 첫 화면은 72px, 상세 시트는 48px다.

## Goals / Non-Goals
- 현재 표시 위치와 크기를 유지하며 투명 PNG 전신을 object-contain으로 표시한다.
- idle/talking/found는 모두 같은 기본 콩눈 이미지를 사용한다. 기존 졸림 이미지를 새 디자인에 섞지 않는다.
- API 계약, 대화 이력, 저장 데이터, AI 모델/추천 로직은 변경하지 않는다.

## Decisions
- 앱 자산: `/brand/companion-bami-v1.png`. 원본은 승인된 v3 시안의 왼쪽 전신에서 배경을 제거한 내장 image_gen 결과다.
- 앱 표시 이름 및 비장식 이미지 alt를 밤이로 통일하고 기본/grounded 서버 프롬프트 모두 이름을 변경한다.
- 구름이 public 파일 두 장은 시안 폴더의 legacy 자료로 옮겨 새 앱 패키지에서 제외한다. 과거 계획/대화 기록을 일괄 치환하지 않는다.
- 현재 기획안·디자인·제품 문서에서 새 결정이 과거 구름이 기록보다 우선함을 명시한다.

## Validation
기존 mascot E2E를 밤이 경로와 이름 검증으로 갱신한다. 데스크톱·360px에서 표시·잘림·새 대화·상세 시트를 확인한다. 사용법 capture config를 실제 실행해 캡처/spotlight를 갱신한다. 운영 빌드와 lint를 실행하고 검증 결과만 완료로 기록한다.
