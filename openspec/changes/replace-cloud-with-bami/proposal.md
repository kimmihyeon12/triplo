# Proposal

## Why
사용자가 밤이의 큰 얼굴·둥근 고동색 선·1번 기본 콩눈 시안을 선택하고 현재 앱의 구름이를 교체하도록 승인했다.

## What Changes
- 챗봇 캐릭터를 다람쥐 밤이로 통일한다. 진입·대화·추천 모두 기본 콩눈 전신을 쓴다.
- 앱 이름 표시·접근성 설명과 두 서버 AI 프롬프트의 인격 이름을 밤이로 변경한다.
- 구름이 이미지는 앱 public에서 제거하고 이전 시안 자료로만 보관한다.
- 사용법 설명·캡처·밝힐 자리, 기획 및 디자인 문서를 갱신한다.

## Capabilities
### New Capabilities
- `bami-chat-mascot`: 승인된 밤이 캐릭터의 앱 표시와 이름 일관성.
### Modified Capabilities
없음(현재 main specs 없음).

## Impact
CompanionFace, 상세 채팅 제목, ai-chat 프롬프트, 사용법 및 기존 캐릭터 E2E. 일정 저장·추천 검증·대화 데이터와 레이아웃은 유지한다. 배포는 이 로컬 구현 작업에 포함하지 않는다.
