# 실제 장소 후보로 AI 일정 짜기·챗봇 답하기

## 왜

AI 일정 짜기와 챗봇이 기억으로 장소 이름을 지어 내고 앱이 뒤에서 카카오로 대조한다. 지어낸 이름이 빠져 어느 날 밥이 없거나 확인 카드가 비고, 비슷한 이름의 다른 곳이 잡힌다. 챗봇 답은 일반론에 머물고, 두 기능 모두 요청 범위('저녁 이후', '맛집만')를 벗어나는 일이 있었다(2026-10-01 사용자 지적).

## 무엇을 바꾸나

- 앱이 카카오 검색으로 장소 후보를 먼저 모아 모델에 보내고, 모델은 후보 번호(ref)로만 고른다. 후보에 없는 항목은 앱이 버린다.
- 두 기능의 지시문을 역할·우선순위 규칙표·출력 전 확인 목록으로 다시 쓴다. 챗봇 코스 답은 장소마다 이유 한 줄과 시간대 순서·동선을 갖춘다.
- 지켜야 하는 규칙은 앱이 결과를 받은 뒤 다시 검사·보정한다.
- 모델(`gemini-3.5-flash-lite`)과 호출 횟수는 그대로다.

## 범위 밖

모델 교체, 구글 검색 근거, Function Calling, 평점·리뷰, 검색 캐시.
