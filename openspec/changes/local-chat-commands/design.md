# 로컬 명령 설계

기존 채팅 send의 AI 호출 전 분기에 순수 명령 해석기를 연결한다. 현재 여행과 필요할 때만 읽는 가계부가 입력이다. 조회는 즉시 답하고 변경은 기존 확인 카드에 이전/이후 값을 제시한다. 모델 응답은 로컬 변경 초안을 생성할 수 없다.

변경 초안은 여행 ID 및 이전 상태와 변경 후 상태를 고정한다. 적용 시 updatedAt을 제외한 여행 내용과 가계부 이전 상태를 비교하여 다른 편집이 있으면 거절한다. 외부 값·좌표는 생성하지 않는다. 한 번의 변경을 되돌리며, 중간에 다른 편집이 있으면 이전 상태를 덮어쓰지 않는다.

대상은 저장된 정확한 이름, 일차, 미배치, 명시적인 전체/종류 조건으로 정한다. 동명·대명사·부정·복합 명령을 추측하지 않는다. 날짜는 로컬 오늘 또는 ISO, 일차를 사용한다. 전체 날짜 이동은 장소와 숙박 날짜를 함께 옮기며, 날짜 미정 전환 시 숙박이 있으면 해제를 요구한다.

경비 추가는 결제자 한 명인 경우에만 자동 지정한다. 여러 참여자가 있으면 기존 가계부 입력 화면으로 안내한다. 금액 수정은 단독 분담/개인 지출에 한정하고 복잡한 분담은 원래 화면에서 수정한다. 균등 나누기는 계산 결과이며 정산 기록을 변경하지 않는다.
