# 로컬 채팅 명령 확장

## Why
일정 조작·저장 정보 조회·경비 계산은 AI 호출 없이 앱이 정확하게 실행할 수 있다.

## What Changes
기존 로컬 날짜 배정을 확장해 장소 날짜·순서·체류시간·고정 시각·메모·제외, 여행 제목·날짜, 저장 정보 조회·중복·숙박 누락·시간 충돌, 경비 조회·기록·수정·삭제·예산·균등 계산, 되돌리기와 화면 링크·텍스트 내보내기를 연결한다.

외부 데이터 조회가 필요한 날씨·실제 경로는 이번 내부 명령에서 제공하지 않는다. 미지원 표현은 실행 가능한 예시로 안내하고 모호한 대상을 임의 선택하지 않는다.
