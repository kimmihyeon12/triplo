# ADDED Requirements

## Requirement: 별도 전국 기록 지도
시스템은 `/lab/map2`에서 실제 출처를 표시하는 대한민국 복셀 지도를 제공해야 한다.

### Scenario: 기록이 있음
- WHEN 사용자가 지도에 진입한다
- THEN 기존 저장소 집계를 사용하고 방문 횟수가 많은 지역은 더 진하고 높게 표현한다.
- AND 미방문 지역은 흰색으로 남는다.

### Scenario: 기록이 없음
- WHEN 집계가 비어 있다
- THEN 흰 지형과 간결한 빈 상태 안내를 제공하고 가상 방문을 삽입하지 않는다.

## Requirement: 앱 디자인과 지도 중심 구성
### Scenario: 페이지 표시
- WHEN 페이지가 렌더링된다
- THEN 공통 PageBar를 사용하고 소개 영역 및 예시 데이터 전환을 표시하지 않는다.
- AND 지도·범례는 panel과 map-visit-low/middle/high 토큰의 동일한 5단계 색상 계산을 사용한다.

## Requirement: 조작 및 접근성
### Scenario: 지역 선택 및 확대
- WHEN 사용자가 지도 블록, 라벨 또는 접힌 목록을 펼쳐 지역을 선택한다
- THEN 지역명과 방문 횟수를 확인할 수 있다.
- AND 확대·축소·초기화 버튼은 실제 카메라에 반영된다.

### Scenario: 로드 실패
- WHEN 경계 또는 집계 로드, WebGL 생성이 실패한다
- THEN 오류 안내와 재시도 버튼을 제공한다.

## Requirement: 지도와 함께 읽는 방문 통계
### Scenario: 집계 요약
- WHEN 기록을 정상적으로 불러왔다
- THEN 방문 시·도 수와 지도에 집계된 누적 방문 횟수를 표시한다.
- AND 종료일이 지난 여행의 장소·숙소 항목을 세며 같은 장소의 중복 항목도 각각 센다는 기준을 안내한다.
- AND 미분류 항목은 별도로 표시한다.

### Scenario: 선택 지역 읽기
- WHEN 지도 또는 목록에서 지역을 선택한다
- THEN 지도 밖 요약 행에 지역명과 방문 횟수가 표시되며 확대·이동 후에도 유지된다.
- AND 시점 초기화 시 선택을 해제한다.

## Requirement: 원본 2.5D 블록 지도 직접 구현

흰 지형과 초록 군집의 큐브는 뚜렷하게 둥근 모서리와 무광 표면, 연한 바닥 그림자로 표현한다. 기본 지형의 옆면과 틈에 진한 회색 음영이 두드러지지 않도록 밝고 고른 보조광을 사용한다.
### Scenario: 방문 집계 표현
- WHEN 원본 디자인을 구현한다
- THEN 흰 큐브 지형 위에 방문 지역별 초록 큐브를 정수 층수로 쌓고 푸른 바다·입체 그림자·핀 라벨·높이 범례를 제공한다.
- AND 이미지 생성이나 생성 이미지의 경계·지명·숫자를 사용하지 않는다.
- AND 블록 군집은 시·도별 합계 표현이며 개별 장소 위치 분포가 아님을 설명한다.
- AND 흰색은 미방문 인증이 아닌 기본 지형으로 안내한다.

### Scenario: 군집 선택
- WHEN 사용자가 초록 큐브를 선택한다
- THEN 해당 군집 소유 지역의 실제 집계를 표시한다.
- AND 라벨은 해당 지점에 실제로 렌더링된 최상층 위에 배치한다.

## Requirement: 방문 볼륨 화면 개편 (이전 표현 요구보다 우선)

### Scenario: 고정 방문 단계
- WHEN 방문 횟수가 1~2/3~5/6~10/11~20/21회 이상이다
- THEN 높이 4/8/14/22/32 비율과 같은 5단계 수치 범례를 사용한다.
- AND 다른 지역 최댓값이 바뀌어도 같은 횟수의 중심 높이·색은 변하지 않는다.
- AND 0 또는 무효 값에는 방문 블록을 만들지 않는다.

### Scenario: 군집과 커버리지
- WHEN 방문 시·도 비율이 50% 이상이다
- THEN 실제 방문 군집의 반경을 넓히고 낮고 연한 주변 블록을 표현한다.
- AND 개별 장소 위치나 실제 방문 면적이 아님을 알리고 가상 방문·가상 지형을 추가하지 않는다.

### Scenario: 유형과 지역 선택
- WHEN 전체/여행/맛집/카페를 선택한다
- THEN 저장된 일정 유형만 사용해 지도 합계와 지역 상세를 같은 조건으로 읽는다.
- AND 문화·예술은 분류 미지원으로 표시한다.
- WHEN 지역을 선택한다
- THEN 지역명·누적 횟수·여행 종료 월 기준 그래프·최근 장소와 기존 여행 링크를 제공한다.
- AND 오래된 상세 응답은 새 선택을 덮어쓰지 않는다.

### Scenario: 탐색과 지도 조작
- WHEN 레이어·확대·축소·포커스·초기화를 조작한다
- THEN 실제 렌더 상태가 변경되고 초기화는 선택도 해제한다.
- WHEN 현재 위치 버튼을 누른다
- THEN 그때만 위치를 요청하고 실패/지원 경계 밖을 안내하며 좌표는 저장하지 않는다.
- AND 전국 시군구 자동 확대는 제공하지 않으며 서울 구별 통계는 해당 지역 쿼리를 읽는 기존 통계 화면으로 연결한다.
- AND 프로필과 하단 탐색은 실제 앱 경로로 연결한다.

### Scenario: 표현과 리소스
- WHEN 페이지를 표시한다
- THEN 공통 PageBar 아래 제목·지역 선택·필터·화이트/연회색 지도·민트~초록 사각 블록·수치 범례·상세를 제공한다. 이전 소개 제외·푸른 바다 결정은 대체한다.
- WHEN 레이어를 다시 그리거나 페이지를 닫는다
- THEN 인스턴스 GPU 버퍼와 geometry를 모두 해제한다.
- WHEN 기록이 없거나 로드가 실패한다
- THEN 빈 상태 또는 재시도를 제공하고 예시로 대체하지 않는다.

## Requirement: 맞물리는 3D 지형과 장소 마커 (2026-09-19, 이전 표현보다 우선)

### Scenario: 연속 지형
- WHEN 전국 지도를 표시한다
- THEN 실제 출처의 육지 샘플을 공유 경계가 일치하는 불규칙 입체 기둥으로 연결하며 정사각 판 사이의 틈을 만들지 않는다.
- AND 흰 지형·초록 군집·밝은 푸른 바다·접지 그림자를 사용하고 지도 밖 UI 및 기존 방문 집계·고정 단계는 유지한다.
- WHEN 지형을 다시 생성하거나 화면을 닫는다
- THEN 병합 및 중간 geometry와 관련 GPU 자원을 해제한다.

### Scenario: 저장한 위치 표시
- WHEN 저장 기록을 읽는다
- THEN 검증된 유효 좌표를 가진 장소·숙소만 기본 핀으로 표시하고 현재 유형 필터와 제외 상태를 적용한다.
- AND 미래 일정도 표시하며 같은 좌표는 하나의 핀과 각 원래 여행 링크로 묶는다.
- AND 지역명에서 위치를 추정하거나 임의 지역 핀을 추가하지 않는다.
- AND 핀 끝이 저장 좌표 투영점과 일치하고 지도 아래쪽 팝업과 긴 목록도 접근 가능하다.

### Scenario: 임시 위치 선택
- WHEN 마커가 없는 육지 표면을 누른다
- THEN 실제 3D 교차 지점에 ‘선택한 위치’ 임시 마커 하나를 활성화한다.
- WHEN 다른 육지 표면을 누른다
- THEN 같은 임시 마커를 새 지점으로 옮긴다.
- WHEN 바다를 누르거나 선택을 닫거나 초기화한다
- THEN 임시 마커를 제거한다.
- AND 드래그 종료는 클릭으로 처리하지 않고, 임시 좌표·이름·주소를 일정에 저장하지 않는다.

## Requirement: 지역 마커만 표시 (2026-09-19 후속 정정, 이전 장소 핀보다 우선)
### Scenario: 같은 지역의 저장 장소
- WHEN 검증된 저장 좌표 여러 개가 같은 시·도에 속한다
- THEN 지역 지형 앵커에 지역명 마커 하나만 표시하며 개별 장소명·링크를 지도 마커에 표시하지 않는다.
- AND 저장 좌표는 변경하지 않는다.
### Scenario: 지역 선택
- WHEN 마커가 없는 지역 지형을 누른다
- THEN 그 지역 앵커에 지역명 임시 마커 하나를 활성화한다.
- WHEN 이미 저장 마커가 있는 지역을 선택한다
- THEN 기존 지역 마커를 활성화하고 임시 마커는 제거한다.

## Requirement: 지역 마커 밀도와 렌더링 예산
### Scenario: 전국 보기와 확대
- WHEN 전국 화면을 표시한다
- THEN 화면에 지역 마커를 최대 6개 표시하며 가까운 핀은 겹치지 않게 생략한다.
- WHEN 1.6배 이상 확대한다
- THEN 표시 상한을 10개로 늘린다.
- AND 선택 지역과 임시 지역을 우선하며 저장 기록과 방문 집계는 유지한다.
### Scenario: 연속 조작
- WHEN 한 프레임 안에서 여러 번 시점 변경을 요청한다
- THEN 실제 렌더링은 한 번으로 합친다.
- AND 그림자는 지형이 바뀔 때만 재계산하고 종료 시 예약된 프레임도 취소한다.

## Requirement: 전체 기록 전용 지도 (이전 유형 필터 요구 대체)
### Scenario: 지도와 지역 상세
- WHEN map2를 표시하거나 지역을 선택한다
- THEN 지도 집계·저장 지역 마커·상세 기록을 모두 all 조건으로 조회한다.
- AND 카테고리 탭·준비 중 분류·유형 안내 문구를 표시하지 않는다.

## Requirement: 간결한 지도 상단 (이전 지역 선택·프로필 행 대체)
### Scenario: 지도 화면 진입
- WHEN map2를 표시한다
- THEN 맨 위 지역 선택 select와 내 프로필 아이콘 행을 표시하지 않는다.
- AND 지도 및 지역 목록에서 지역을 선택할 수 있다.

## Requirement: 밝고 부드러운 지도 음영
### Scenario: 지도 렌더링
- WHEN 지형과 방문 블록을 표시한다
- THEN 밝은 보조광과 연한 접지 그림자를 사용해 지형 옆면의 어두운 대비를 줄인다.
- AND 밝은 하늘색 바다와 민트·녹색 단계로 표현하며 방문 단계와 마커·성능 규칙은 유지한다.

## Requirement: 통계 기본 지도와 구 지도 정리 (이전 실험실 라우트 요구 대체)
### Scenario: 통계 진입
- WHEN 로그인한 사용자가 /stats에 진입한다
- THEN 현재 3D 방문 지도를 앱 공통 PageBar·카드·딥 블루 조작 색으로 표시한다.
- AND 지도 전용 하단 메뉴와 지역 select·프로필·카테고리는 표시하지 않는다.
### Scenario: 상세와 호환성
- WHEN 서울 구별/지역 전체 기록을 연다
- THEN /stats/details에서 기존 상세 기능을 제공하고 전국 복귀는 /stats로 연결한다.
- WHEN 기존 서울 구 코드가 /stats의 region 쿼리로 전달된다
- THEN /stats/details에 동일 코드를 전달한다.
- WHEN 3D 렌더러를 사용할 수 없다
- THEN 일반 통계로 이동하는 대체 경로를 제공한다.
### Scenario: 이전 실험 지도 제거
- WHEN 앱 라우트와 기능 파일을 구성한다
- THEN /lab/map·/lab/map2 라우트, record-map 하위 파일 및 독립 지도 HTML을 제거한다.
- AND 현재 지도 코드는 stats 기능에 소속되며 기존 인증 가드를 유지한다.
