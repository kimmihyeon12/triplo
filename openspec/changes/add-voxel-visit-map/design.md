# 설계

Angular standalone 페이지가 기존 LocalVisitStats.provinceCounts() 집계 결과를 받고 Three.js InstancedMesh로 국토 블록을 그린다. 기존 SVG `/stats`와 분리해 새 라우트에서만 Three.js를 로딩한다.

southkorea-maps의 통계청 2013 단순화 시·도 GeoJSON을 별도 파일로 보관한다. 기존 사각형 fixture는 덮어쓰지 않는다. 과거 행정경계임을 화면에 명시한다. KOSTAT 코드와 기존 집계 코드를 매핑하며 7km 격자로 샘플링한다.

방문 0은 흰색·기본 높이, 양수는 화면의 최대 방문 수 대비 5단계 초록색으로 표현한다. 같은 시·도는 동일한 색을 갖는다. 중앙 기둥 형태는 지역 집계를 표현하는 장식적 높이이며 개별 장소의 좌표 또는 빈도가 아니다. 빈 기록은 흰 지형과 안내를 표시한다. 예시 기록 전환은 최신 사용자 요청에 따라 제거한다. 검증 데이터는 4300 테스트 저장소에서만 주입하고 복구한다.

지도 이동·확대·축소·초기화 및 지역 선택을 지원한다. 키보드는 라벨·버튼·방문 목록을 사용한다. 렌더링은 변경 시에만 수행하며 화면 해제 시 observer, listener, controls, mesh, geometry, material, shadow, renderer를 정리한다. 지속 애니메이션은 없다.

이 결정은 기존 방문 통계 설계의 SVG 선택을 `/stats`에 한정하고, 독립 실험실 화면에서만 WebGL을 허용한다. 실제 방문 확정이 아닌 기존 종료일 기반 집계 의미는 유지한다.

## 지도 전용 표현으로 갱신 (2026-09-18)

참조 이미지의 흰 복셀·녹색 빈도 표현을 앱 디자인에 맞춘다. 소개 문구·자체 헤더·예시 전환·대형 하단 목록을 제거하고 공통 PageBar와 접힌 접근성 목록을 사용한다. 실제 방문 기록만 표시하며 미방문은 흰색이다.

Three.js 색상은 CSS의 `--color-panel`, `--color-ok-tint`, `--color-ok-ink`를 읽는다. 빈도별 5단계는 두 초록 토큰 사이의 sRGB 보간으로 생성하고 범례도 같은 함수를 쓴다. CSS 배경·글자·버튼·포커스·모서리·그림자는 기존 앱 토큰을 사용한다. RoundedBoxGeometry로 블록 모서리를 부드럽게 한다. 기존 집계 규칙은 바꾸지 않는다.

## Higgsfield 참고 적용 및 통계 가독성 (2026-09-18)

생성된 `docs/design/references/map2-higgsfield.png`의 중성 바탕, 낮은 입체감, 간결한 수평 범례와 선택 지역 요약을 적용한다. 생성 이미지의 임의 경계·지명·숫자는 제품 데이터로 사용하지 않는다. 앱 공통 PageBar·UiButton·UiIcon·UiSpinner 및 Tailwind 토큰을 사용하며 화면 전용 CSS를 제거한다. 조작·선택은 딥 블루, 방문 빈도만 초록색이다.

지도 위 요약에는 방문 시·도 수/전체 17개와 누적 방문 횟수를 표시한다. 누적 방문은 종료일이 지난 여행에 저장된 장소·숙소 항목 수이며 고유 장소 수나 실제 방문 인증이 아니다. 미분류 항목은 지도 합계에서 제외하고 별도로 안내한다. 지역 선택 정보는 지도 밖의 고정된 요약 행에 두어 확대·이동 중에도 읽을 수 있다. 목록은 접힌 상태를 유지하고 모바일 지도 높이와 라벨 밀도를 낮춰 조작 공간을 확보한다.

## 사용자 원본 이미지 직접 재현 — 최신 결정

후속 둥근 표현 조정: 흰 지형과 초록 군집 모두 큐브 한 변의 18% 모서리 반경, 곡면 분할 3을 적용한다. 무광 재질과 더 연한 바닥 그림자로 원본의 부드러운 블록 질감을 따른다. 군집의 층수·좌표·집계는 유지한다.

회색 음영 보정: HemisphereLight의 하부 색상을 밝은 #edf2f2, 세기를 2.2로 바꾸고 백색 AmbientLight 0.85를 추가한다. 방향광은 2.4로 낮춰 옆면·블록 틈의 대비를 줄인다. 접지 그림자는 #829cad, 불투명도 0.09로 낮춰 참고 이미지의 밝은 흰 점토 지형을 따른다.

사용자는 이미지 생성을 원하지 않으며 첨부한 2.5D 블록 지도 자체의 구현을 요청했다. 이전 Higgsfield 생성물과 낮은 높이·수평 범례 방향은 이번 결정으로 대체한다. 원본 왼쪽 전국 지도의 두꺼운 흰 큐브 지형, 푸른 바다, 초록색 계단 군집, 접지 그림자, 핀과 흰 라벨, 우하단 높이 범례를 Three.js로 직접 구현한다. 상단바와 통계·목록 접근성은 유지한다. 오른쪽 서울 상세 화면의 사진·필터·월별 그래프는 현재 시·도 집계 범위를 넘어가므로 추가하지 않는다.

실제 출처 경계를 14km 간격으로 샘플링한다(513개 육지 셀, 17개 시·도 유지 확인). 육지는 흰 큐브 한 층이며 방문 집계는 지역 중심과 가장 가까운 실제 육지 셀을 기준으로 1~6층의 분리된 큐브를 쌓는다. 군집의 주변 장식 셀은 인접 행정경계를 넘을 수 있고 지역 면적 전체의 색상 분포를 뜻하지 않는다. 겹치는 군집의 셀은 가장 가까운 기준점에 배정하고 각 지역의 중심 셀은 보존한다. 원래 육지의 지역 코드와 위에 그린 군집의 집계 코드를 별도로 보관해 클릭 결과를 정확히 연결한다. 모든 라벨은 해당 앵커에 실제 렌더링된 층의 위에 배치해 인접 군집에 가려지지 않게 한다. 바다에 가상 지형이나 가상 장소를 추가하지 않는다. 화면에는 시·도별 합계 표현이며 개별 장소 위치 분포가 아니라는 설명을 둔다.

표현용 위치·층수는 저장하지 않으며 실제 방문 값은 LocalVisitStats에서만 읽는다. 렌더링은 변경 시에만 수행하고 분리된 큐브도 InstancedMesh 하나로 그린다. 카메라는 직교 투영, 그림자는 실제 광원과 ShadowMaterial 바닥으로 구현한다.

색상은 지도 전용 theme.css의 map-water/light 및 map-visit-low/middle/high 토큰으로 정의한다. 원본의 밝은 연두→선명한 초록→짙은 녹색을 5단계로 보간하며 군집 내부 밝기는 높이와 집계 비율에 따라 달라진다. 범례의 흰색은 '기본 지형'으로 설명한다. 모바일에서는 카메라 여백으로 제주를 포함하고 우측 핀의 라벨을 왼쪽으로 펼쳐 조작 버튼과의 겹침을 줄인다.
# 방문 볼륨 개편 — 첨부 요구사항 (2026-09-18)

최신 사용자 요청은 map2에 2.5D 볼륨형 방문 지도와 여행 기록 화면 구성을 적용하는 것이다. 아래 과거 원본 재현 결정 중 소개·필터·상세 제외, 상대 방문 단계는 이 절로 대체한다. Angular 21과 실제 저장소·2013 시·도 경계는 유지한다.

방문 단계는 1~2/3~5/6~10/11~20/21회 이상이며 높이는 4/8/14/22/32의 비율을 사용한다. 20회 경계 중복을 해소했다. 다른 지역의 방문 최댓값이 바뀌어도 같은 횟수의 색·중심 높이는 같다. 부드러운 사각 블록 군집의 중심은 높고 진하며 외곽은 낮고 연하다. 방문 시·도가 절반 이상이면 실제 방문 군집의 반경을 넓혀 밀도를 표현한다. 방문하지 않은 지역에 기록을 추가하지 않으며 군집은 개별 장소 좌표를 의미하지 않는다.

화이트·연회색 지도 바탕과 민트~초록 단계, 지역 선택·프로필, 요청한 제목, 일정 유형 필터, 지도 조작, 수치 범례, 선택 지역의 여행 종료 월별 집계와 최근 장소를 제공한다. 카테고리는 저장된 일정 유형만 사용하며 문화·예술을 추정하지 않는다. 위치 조회는 사용자가 버튼을 누를 때만 요청하고 저장하지 않는다. 탐색은 기존 페이지에 연결한다. 전국 시군구 경계는 미지원이며 서울 상세는 기존 통계 화면으로 연결한다. 생성 이미지·가상 방문·가상 장소 정보는 사용하지 않는다.

구현 순서와 검증은 `docs/superpowers/plans/2026-09-18-map2-visit-volume.md`를 따른다. 이 절은 설계이며 완료 여부는 tasks.md의 실제 검증 결과로 판단한다.

## 2026-09-19 맞물리는 지형·저장 마커 — 현재 설계

이 절이 과거 정사각 큐브·InstancedMesh·지역 자동 라벨·중성 배경 결정을 대체한다. 지도 밖 UI는 변경하지 않는다. 6.5km 육지 샘플 2,403개와 17개 시·도를 유지하며 결정적인 Voronoi 공유 경계를 그대로 ExtrudeGeometry로 돌출한다. 평면 축소·틈·사각 구획선을 만들지 않는다. 흰 바닥과 초록 높이를 연속 기둥으로 렌더하고 주변 높이를 결정적 변이로 다듬되 방문 단계별 중심 높이를 보존한다. 기존 군집 반경은 14/cellSize로 보정해 물리적 크기를 유지한다. 지오메트리는 하나의 Mesh로 병합하고 삼각형별 군집/육지 소유 지역을 보관한다. 재생성 시 이전 및 중간 geometry를 해제하고 화면 종료 때 재질·그림자·컨트롤·리스너·renderer도 정리한다. 지속 렌더 루프는 없다.

SavedMapPlaces가 TRIP_REPOSITORY의 여행을 읽고 util/saved-markers가 검증된 유한 좌표만 추출한다. 제외·여유시간은 배제하고 일정 유형 필터를 적용한다. 미래 일정도 포함하며 정확히 동일한 좌표는 합치고 원래 항목 링크를 모두 보존한다. 지역명에서 좌표를 만들지 않는다. 기존 종료일 경과 방문 집계와 분리한다.

핀은 저장 위경도를 기존 투영으로 변환하고 수직 raycast로 표면 높이만 맞춘다. 가로 좌표는 이동하지 않는다. 핀 끝을 화면 투영점에 고정하고 이름은 옆에 배치한다. 팝업은 아래쪽에서 위로 전환하고 지도 너비 안으로 보정하며 긴 목록은 스크롤한다. 지형 클릭은 실제 mesh 교차점에 임시 핀 하나를 만들며 바다·초기화·닫기로 제거한다. 5px 이상 움직인 포인터는 원위치로 돌아와도 클릭으로 처리하지 않는다. 임시 상태는 메모리뿐이며 저장소에 쓰지 않는다.

## 2026-09-19 후속 정정: 지역 마커만 표시 — 현재 우선

최신 사용자 요청에 따라 개별 장소 핀·장소명·지도 내 장소 링크를 제거한다. 저장된 검증 좌표가 속한 시·도를 실제 경계로 판별하고 같은 지역은 지역명 마커 하나로 합친다. 표시 위치는 해당 지역의 지형 앵커이며 저장 좌표를 변경하지 않는다. 마커 없는 지형을 클릭하면 클릭한 군집/육지의 지역 앵커에 지역명 임시 마커 하나를 표시한다. 이미 저장 마커가 있는 지역은 기존 핀을 선택해 중복하지 않는다. 지역 상세와 초기화·닫기는 유지하며 지도 외 UI와 지형은 변경하지 않는다. 이전 개별 위치 핀과 교차점 임시 핀 요구를 이 절로 대체한다.

## 2026-09-19 지역 마커 과밀·렌더링 부하 개선 — 현재 우선

전국 화면의 지역 마커는 최대 6개, 1.6배 이상 확대에서는 최대 10개로 제한한다. 화면상 가까운 핀은 겹치지 않도록 생략하며 현재 선택 지역과 임시 지역 핀을 우선한다. 생략한 지역은 지형 클릭·확대·기존 지역 목록으로 선택할 수 있다. 저장 지역 데이터와 방문 집계는 삭제하거나 줄이지 않는다.

3D 지형과 공유 경계는 유지한다. 같은 프레임의 연속 변경은 requestAnimationFrame 한 번으로 묶고 정지 상태에서는 렌더하지 않는다. 정적인 광원·지형의 그림자는 지형/레이어 재생성 때만 갱신하며 이동·확대 때 다시 계산하지 않는다. 화면 종료 시 대기 프레임도 취소한다.

## 2026-09-19 전체 기록만 표시 — 최신 정정

map2에서 여행·맛집·카페·문화·예술 카테고리 탭과 유형 안내를 제거한다. 단일 ‘전체’ 탭도 두지 않고 지도 집계·저장 지역 마커·지역 상세를 항상 all 조건으로 읽는다. 기존 지역 마커 표시 상한과 3D 최적화는 유지한다. 이전 카테고리 선택 요구를 이 결정으로 대체한다.

사용자 요청에 따라 map2 맨 위 지역 선택 select와 내 프로필 아이콘 행을 제거하고 빈 상단 여백도 정리한다. 지역 선택은 지도와 기존 지역 목록으로 제공한다. 이전 상단 지역 선택·프로필 요구를 이 결정으로 대체한다.

## 2026-09-19 지도 밝기 보정 — 현재 표현

어둡게 느껴지는 지도 음영을 완화한다. 흰 지형의 보조광을 높이고 방향광 대비를 낮춘다. 접지 그림자 불투명도는 0.21에서 0.10으로 줄이고 밝은 청회색으로 변경한다. 바다는 더 밝은 하늘색, 방문 단계는 밝은 민트에서 중간 녹색으로 보정한다. 단계 구분과 입체 높이, 지역 마커 상한, 렌더 병합과 그림자 캐시는 유지한다.

## 2026-09-19 통계 기본 화면으로 통합 — 현재 경로·디자인

기존 map2를 로그인 보호된 `/stats` 기본 화면으로 옮긴다. 구현은 `features/stats/feature/visit-map`과 stats의 data/model/ui/util에 통합하며 별도 voxel-map 기능 폴더는 남기지 않는다. 이전 `/lab/map`의 record-map 하위 파일과 테스트, 단독 lab-voxel HTML을 삭제한다. `/lab/map`·`/lab/map2` 라우트와 실험실 링크를 제거/갱신하며 삭제 경로는 앱의 일반 미등록 경로 처리에 따른다.

현재 앱의 PageBar ‘방문 통계’, 22px 제목·14px 안내, 중성 배경·흰 카드·공통 모서리와 딥 블루 조작 색을 사용한다. 기존 지도 전용 하단 5개 메뉴는 제거한다. 흰 3D 지형·밝은 바다·초록 방문 단계는 데이터 표현으로 유지하고 전체 기록만 조회한다. 지역 select·프로필·카테고리 UI를 되살리지 않는다. 마커 상한과 렌더 병합·그림자 캐시는 유지한다.

기존 SVG/목록 통계는 `/stats/details`에 남겨 서울 구별 통계와 지역 전체 기록, WebGL 오류 시 대체 화면을 제공한다. 상세 화면의 전국 복귀는 `/stats`로 연결한다. `/stats?region=시도코드`는 지도에서 선택하고 기존 서울 구 코드 쿼리는 `/stats/details`로 전달한다. 저장소·실제 방문 집계·개인정보 기본 비공개·인증 가드는 유지한다.
