# AI 없이 미배치 장소 날짜 배정

## Why
저장된 장소를 날짜에 배정하는 명확한 요청에도 모델을 호출하면 비용과 지연이 발생하고, 실행 대상이 불명확해진다.

## What Changes
- 미배치 장소 전체를 N일차·첫날·오늘·내일·ISO 날짜로 배정하는 명령을 로컬 처리한다.
- 기존 확인 카드와 되돌리기를 사용하며 모델 호출 한도를 소모하지 않는다.
- 모호한 조건, 날짜 충돌, 기간 밖 날짜는 로컬 안내로 해결한다.

## Impact
채팅 명령 해석, 초안 생성·검증·적용, 추천 칩. 기존 장소 데이터만 사용한다.
