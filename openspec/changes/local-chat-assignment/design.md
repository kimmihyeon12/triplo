# 설계

명확한 전체 배정 요청을 모델 호출 이전에 해석한다. 오늘은 기기의 로컬 날짜이며 일차는 여행 시작일 기준이다. 오늘과 1일차가 서로 다르면 날짜 선택 칩을 제공한다. 이해하지 못한 조건이나 부정 표현은 전체 선택으로 확대하지 않는다.

초안은 미배치·미제외 장소 ID를 현재 순서대로 고정한다. 확인 카드는 목적 날짜의 기존 장소와 추가될 장소를 보여준다. 적용 직전 날짜 범위와 모든 대상의 미배치·미제외 상태를 재검사한다. 이후 추가된 장소는 초안에 끼워 넣지 않는다. 기존 날짜의 장소 뒤에 순서대로 배정하며 주소·좌표·메모 등은 그대로 유지한다. 전체 변경은 한 번에 되돌린다.
