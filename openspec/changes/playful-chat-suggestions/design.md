# 설계

listChips와 tripChips의 기본 문구를 변경한다. 임의의 새 액션을 만들지 않고 실제 전송 가능한 질문을 사용한다. 랜덤 여행지 뽑기는 기존 로컬 처리, 테마 코스는 기존 추천 경로를 사용한다. 마지막 응답에 후속 칩이 있으면 계속 우선 표시하여 날짜 확인 등 대화 흐름을 유지한다.

전체 채팅(`/trips/chat`)의 후속 질문에도 같은 원칙을 적용한다. 랜덤 결과는 재추첨과 해당 지역의 먹방·카페·사진·느긋한 하루를 제안한다. 픽스처 응답도 테마 질문을 사용한다. 저장된 대화는 삭제하지 않고 표시 시 알려진 옛 탐색 문구만 교체한다. 날짜 배정·장소 삭제의 확인 선택지는 원문을 보존한다.
