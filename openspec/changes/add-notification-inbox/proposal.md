# 알림 내역 추가

푸시를 놓치거나 켜지 않은 사람도 지난 알림을 앱 안에서 다시 보게 한다(2026-10-06 사용자 요청). 2026-10-01 푸시 설계의 '앱 안 알림함은 범위 밖' 결정을 바꾼다.

## 범위

- 내 정보 > 소식에 `알림 내역` 줄과 안 읽은 수. 목록은 최근 것부터, 줄을 누르면 알림이 가리키는 화면으로 간다. 화면을 열면 모두 읽음.
- 서버 표 `notification_inbox`(본인만 읽기, 읽음 표시는 `mark_notifications_read`로만). 알림을 대기열에 쌓을 때 함께 남긴다.
- 푸시를 켜지 않아도 남긴다. 알림 설정에서 끈 종류는 남기지 않는다. 공지는 공지 알림을 켠 사람마다 남긴다.
- 30일이 지나면 하루 한 번 지운다(pg_cron).

## 범위 밖

- 알림 하나씩 지우기·읽음 표시, 상단 바 종 아이콘, 실시간 갱신.

기획안 44절. 마이그레이션 `20261006120000_notification_inbox.sql`, `20261006120001_notification_inbox_cleanup_cron.sql`.
