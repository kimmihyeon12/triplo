## ADDED Requirements

### Requirement: 지난 알림 보기
시스템은 로그인한 사용자에게 최근 30일 안의 자기 알림을 최근 것부터 보여야 한다(SHALL). 푸시 구독 여부와 상관없이 남겨야 하며(SHALL), 알림 설정에서 끈 종류는 남기지 않아야 한다(SHALL).

#### Scenario: 푸시를 켜지 않은 사람
- **WHEN** 푸시를 켠 적 없는 사람의 여행에 다른 멤버가 합류한다
- **THEN** 그 사람의 알림 내역에 참여 알림이 남는다

#### Scenario: 끈 종류
- **WHEN** 사용자가 '함께 편집 소식'을 끈 뒤 다른 멤버가 가계부를 고친다
- **THEN** 알림 내역에는 남지 않는다

#### Scenario: 일정을 여러 번 고친다
- **WHEN** 다른 멤버가 10분 안에 일정을 여러 번 고친다
- **THEN** 알림 내역에는 한 번만 남는다

### Requirement: 안 읽은 알림과 이동
시스템은 내 정보에 안 읽은 알림 수를 보이고, 알림 내역을 열면 모두 읽음으로 해야 한다(SHALL). 줄을 누르면 알림이 가리키는 앱 안 화면으로 가야 한다(SHALL).

#### Scenario: 내역을 연다
- **WHEN** 안 읽은 알림이 있는 사용자가 알림 내역을 연다
- **THEN** 이번 화면에서는 새 표시가 보이고, 내 정보로 돌아가면 새 알림 수가 사라진다

### Requirement: 본인 내역만
시스템은 다른 사람의 알림 내역을 읽거나 앱에서 내역을 직접 쓰지 못하게 해야 한다(SHALL).
