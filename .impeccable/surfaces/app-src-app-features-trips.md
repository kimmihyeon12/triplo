# Surface brief: 내 여행 (trip list · trip detail · forms · map states)

Scope: `/trips`, `/trips/new`, `/trips/:id` (전체/날짜별/숙소 탭, 날짜별·숙소 지도), `/trips/:id/edit`, stop/stay forms(장소 검색 상자 포함). Visitor mode: Operate.
Audience: 프로젝트 소유자와 친구들, 20~30대 국내 자유여행. Job: 여행 생성 → 장소·숙소 검색 등록 → 지도·목록으로 전체 확인 → 같은 기기에서 재열기. Task frequency: 여행당 며칠간 여러 번, 짧은 편집 세션.
Content: 사용자가 입력하거나 검색으로 고른 여행·지역·장소·활동·숙박. 확인된 좌표만 지도에 표시하고 이동시간은 미확인. Constraints: 360px 모바일과 키보드만으로 조작, 드래그 없음, WCAG 2.2 AA, 자동 삭제 없음.
Unresolved: 서비스명, 경로 제공자, 로컬 LLM 화면.

## Direction contract

THESIS: 이 화면은 국내 여행 앱 사용자가 이미 아는 관례를 흠 없이 실행한 것이다. 장식·표시 서체·스티커를 거부하고, 위계·여백·구분선·굵기만으로 하루의 구성을 읽게 한다. 다른 점은 색이 아니라 정직함이다: 미확인·미정·충돌이 회색 위계 위에 노랑·로즈로만 드러난다.

OWN-WORLD: 바탕 미지근한 회백색(#F7F6F4), 흰 카드(14px, 1px 선 없이 얕은 그림자), 카드 안 목록은 1px 구분선. 탭은 밑줄(코랄 2px), 날짜 칩은 알약(선택 = 잉크 채움 흰 글자), 주 동작 버튼은 코랄(#C9452F) 채움 흰 글자 12px 모서리. 서체는 Noto Sans KR 한 가족(400/500/700), 제목 -0.02em, 본문 -0.01em. 색 법칙: 코랄=주 동작·현재 선택·순번 마커, 라벤더=숙소, 버터=확인 필요·미확인만, 로즈=충돌·오류만, 민트=완료. 아이콘 2px 선 SVG. 파랑·민트 강조 금지.

STORY: 사용자는 여행을 열면 굵은 제목 아래 밑줄 탭과 날짜 칩, 그 아래 지도 카드와 순번 목록을 본다. 어느 날 어디를 가고 어디서 자는지 순번·칩으로 읽고, 지도 마커와 목록이 같은 순번으로 대응한다는 것을 신뢰한다. 지도가 없거나 실패해도 같은 카드 안에서 이유와 다음 행동을 본다.

FIRST VIEWPORT (`/trips/:id`, 360px): 흰 상단 바(코랄 점 + ‘내 여행’). 판 없는 머리글에 제목(28px 700), 기간·N박(회색), 지역 순서(회색, 얇은 선 연결), 저장 상태 칩, [편집] 흰 버튼. 밑줄 탭 [전체 / 날짜별 / 숙소]. 날짜별: 날짜 알약 칩 행 → 지도 카드(280px, 범례 한 줄) → 숙소 칩 → 한 카드 안의 순번 목록(28px 코랄 원 번호, 1px 구분선, 이동 구간 행) → 하루 합계 → 하단 고정 코랄 [장소 추가] + 흰 [숙소 추가]. 데스크톱(≥900px): 왼쪽 날짜 칩 열(둥근 사각) + 오른쪽 지도(380px)·목록.

FORM: 카테고리 표준(사용자 선택). 롤 배정(81aaffeb 인덱스 5, 인스탁스 앨범)과 픽(스티커 플래너)은 사용자가 보고 거절한 대안으로 기록만 남긴다.

Map states (designed): 제공자 확인 중(회색 바탕 문구) / 불러오는 중(코랄 스피너, 모션 감소 시 정지) / 연결 안 됨(키 파일 안내, 회색 아이콘) / 오류(로즈 1px 윤곽, 로즈 아이콘, 사유) / 표시할 위치 없음(안내 문구) / 준비됨(마커·안내선·범례). 범례에 ‘지도에 없음 n개 · 위치 미확인’ 버터 칩.

Signature interaction: [위로]/[아래로] 순서 변경 시 옮겨진 행의 배경이 코랄 틴트로 켜졌다 400ms에 꺼진다. 모션 감소 설정에서는 틴트만 잠시 유지된다. 마커↔카드 선택은 행 배경 코랄 틴트와 마커 확대 링으로 동기화한다.

Adaptations (근거): 360px에서 숙소 칩을 날짜 카드 아래 줄로 내린 것은 40px 배지 + 본문 폭에서 칩이 줄바꿈되기 때문이다. 한글 서체 자체 호스팅(Pretendard 또는 Noto Sans KR 서브셋)은 PWA 오프라인 단계에서 처리한다(현재 Google Fonts CDN, 시스템 서체 대체).

Cross-surface reach: 발견·AI 추천 단계 화면·기록지도·가계부도 같은 회백색 바탕·흰 카드·밑줄 탭·코랄 하나 체계를 쓴다. 선택형 AI 결과 화면은 지도 카드 → 날짜 칩 → 체크박스 목록 → 하단 고정 담기 버튼으로 같은 문법을 재사용한다. Honest risk: 다른 여행 앱과 구분이 약하다. 구분은 정직한 미확인 표시와 검증된 좌표만 그리는 지도에서 온다.
