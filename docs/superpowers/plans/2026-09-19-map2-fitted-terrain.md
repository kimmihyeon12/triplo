# Map2 맞물리는 입체 지형과 장소 마커

사용자가 다시 첨부한 이미지를 직접 시각 기준으로 사용한다. 지도 밖 UI는 변경하지 않는다. 기존 정사각 판을 규칙적으로 늘어놓는 표현을 불규칙한 Voronoi 조각의 연속 지형으로 교체한다. 공유 경계는 동일하게 사용해 간격을 벌리지 않는다. 실제 출처 국토를 더 촘촘히 샘플링하고 흰 지형·민트에서 짙은 초록 군집·밝은 푸른 바탕·부드러운 접지 그림자·기울어진 직교 카메라를 적용한다.

저장된 장소/숙소 중 확인된 유효 좌표가 있는 항목만 자동 마커를 만든다. 이름이나 지역 중심으로 좌표를 만들지 않는다. 날짜가 미래인 저장된 장소도 표시하며 기존 방문 군집의 종료일 집계와 구분한다. 제외·여유시간은 제외하고 현재 유형 필터를 따른다. 동일 좌표는 하나의 마커로 모은다. 좌표가 없는 지형을 누르면 그 3D 교차 지점에 임시 선택 마커 하나를 표시한다. 다른 지점을 누르면 옮기며 저장·추정 지명·주소 생성은 하지 않는다. 바다 클릭/초기화로 임시 마커를 닫는다. 저장 마커는 명칭과 원래 여행 링크를 제공한다.
