# Map2 방문 볼륨 지도 구현 계획

**목표:** 첨부한 여행 기록 지도 요구사항을 기존 Angular map2에 적용한다.
**설계 원본:** `openspec/changes/add-voxel-visit-map/design.md`의 방문 볼륨 개편 절.
**구조:** 실제 저장소 집계를 유지하고 고정 방문 단계·군집 배치·화면 상태를 분리한다. 시각 표현 좌표는 저장하지 않는다. Angular 21, Three.js, 기존 공통 UI와 Tailwind를 사용한다.

## 작업 순서

- [x] `visit-style.spec.ts`에 경계값 0/1/2/3/5/6/10/11/20/21과 다른 지역 최댓값 독립성 검증을 추가하고 실패를 확인한다. `visit-style.ts`에 4/8/14/22/32 높이와 5단계 색상을 구현한다.
- [x] `block-layout.spec.ts`에 방문량별 반경, 중심 높이, 50% 이상 커버리지의 확산, 잘못된 값 제외 검증을 추가한다. `block-layout.ts`를 고정 단계에 연결하고 `voxel-scene.ts`는 부드러운 사각 블록과 요청 시 렌더링을 사용한다.
- [x] 저장소의 기존 종료일 기준과 제외 규칙을 유지하며 선택한 일정 유형으로 집계와 최근 장소를 읽는다. 월별 막대는 실제 방문일이 아닌 여행 종료 월임을 표시한다. 없는 문화 분류를 이름에서 추정하지 않는다.
- [x] `voxel-map.ts/html`에 지역 선택·프로필·제목·필터·지도 레이어·위치/포커스·고정 범례·월별/최근 장소 카드와 기존 경로를 연결한 탐색을 구현한다. 미지원 시군구 경계를 합성하지 않는다.
- [x] 기획안, OpenSpec 제안·설계·요구사항·작업, 개발 안내 및 디자인 기록을 같은 범위로 갱신한다.
- [x] 단위 테스트·구조 검사·운영 빌드 및 별도 4300 test 앱의 360/1280px 빈 상태/기록/선택/필터/오류 재시도를 검증하고 실제 결과를 기록한다.

## 데이터 제약

전국 시군구 확대와 문화·예술 분류는 검증된 경계·저장값이 없어 미지원으로 표시한다. 서울 구별 집계는 기존 통계 화면으로 연결한다. 예시 기록은 브라우저 검증의 격리 저장소에서만 사용한다. 발견하기는 기존 AI 일정 화면으로 연결한다. 기존 `/stats`, `/lab/map`, 일정 저장 형식은 유지한다.
