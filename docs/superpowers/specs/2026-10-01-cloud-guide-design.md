# 구름이가 안내하는 앱 사용법 설계

2026-10-01 작성. 사용자 요청: 구름이가 앱 사용법을 안내하는 화면을 만든다(구름이 자체의 사용법이 아니다). 실제 앱 화면을 캡처해 쓴다. 처음 가입하고 로그인한 사람에게 보여 주고, 내 정보에서 다시 볼 수 있게 한다.

## 1. 보여 주는 때

| 언제 | 어떻게 |
| --- | --- |
| 처음 가입(닉네임 입력을 마친 직후) | 여행 목록으로 가기 전에 안내 화면(`/guide`)을 연다. 건너뛰기 가능 |
| 이미 본 사람이 다시 로그인 | 보여 주지 않는다 |
| 내 정보 → 설정 묶음 "사용법 보기" | 언제든 다시 연다 |

본 기록은 계정의 사용자 정보(`user_metadata.travel_guide_seen`)에 남긴다. 기기를 바꿔도 다시 뜨지 않는다. 테스트 앱·미리보기는 계정별 기기 저장을 쓴다.

## 2. 화면

한 장씩 넘기는 안내(6장). 각 장은 **위에 실제 앱 캡처**(휴대폰 틀 안), **아래에 구름이 말풍선**(2줄 이내)으로 구성한다.

```text
┌──────────────────────────┐
│   [건너뛰기]        2 / 6 │
│  ┌────────────────────┐  │
│  │  실제 앱 화면 캡처   │  │  ← 강조할 곳에 둥근 표시
│  └────────────────────┘  │
│  (구름이) 지역과 날짜만 고르면 │
│          하루 코스를 짜 줘요   │
│   ● ● ○ ○ ○ ○            │
│  [이전]          [다음]   │
└──────────────────────────┘
```

| 장 | 캡처 | 구름이 말 |
| --- | --- | --- |
| 1 | 여행 목록 | 안녕! 나는 구름이야. 여행 계획을 같이 도와줄게 |
| 2 | 일정 짜기 결과(시간순 코스) | 지역·날짜·취향만 고르면 하루 코스를 짜 줘. 마음에 안 드는 곳은 빼고 담으면 돼 |
| 3 | 여행 상세(날짜별 일정·지도) | 담은 곳은 날짜별로 정리되고 지도에서 동선을 볼 수 있어 |
| 4 | AI 챗봇 대화와 확인 카드 | 궁금한 건 나한테 물어봐. 추천은 확인 카드로 보여 주고, 담기는 네가 정해 |
| 5 | 가계부·정산 | 쓴 돈은 가계부에, 영수증은 사진으로 읽어 줘. 누가 얼마 보낼지 계산해 줘 |
| 6 | 함께하는 사람 초대 | 친구를 초대하면 일정과 가계부를 함께 고칠 수 있어. 이제 첫 여행을 만들어 볼까? |

마지막 장의 버튼은 "시작하기"이고, 처음 가입한 사람은 여행 목록으로, 내 정보에서 연 사람은 내 정보로 돌아간다.

- 구름이 이미지는 지금의 2D 전신(`brand/companion-cloud-*`)을 쓴다. 장마다 표정 하나(미소)로 통일한다.
- 좌우로 밀어 넘기기, 키보드 화살표, 하단 점으로 이동. 화면 읽기 프로그램에 "6장 중 2장"을 알린다. 움직임 줄이기 설정에서는 넘김 애니메이션을 끈다.
- 디자인은 [DESIGN.md](../../design/DESIGN.md) 토큰과 공통 버튼·상단 바를 따른다(Impeccable 제품 화면 규칙).

## 3. 캡처 만들기

- 테스트 앱(고정 데이터)으로 Playwright 스크립트(`app/scripts/capture-guide.mjs`)가 6개 화면을 390×844로 찍어 `app/public/guide/*.webp`로 저장한다. 강조 표시는 캡처 위에 앱이 그린다(이미지에 굽지 않는다). 화면이 바뀌면 스크립트를 다시 돌린다.
- 캡처에는 테스트 데이터만 나온다. 실제 사용자 정보가 들어가지 않는다.
- 이미지 6장의 합은 600KB 이하로 둔다(webp). 안내 화면은 처음 열 때만 받는다(지연 로딩).

## 4. 테스트

- 단위: 본 기록 저장·읽기, 처음 가입 흐름에서만 열기.
- e2e: 닉네임 입력 후 안내가 열리고 건너뛰면 여행 목록, 다시 로그인하면 안 열림, 내 정보 "사용법 보기"로 다시 열기, 360px 가로 넘침 없음, 키보드로 넘기기.

## 구현 기록 (2026-10-01)

- 사용자 요청으로 6장에서 12장으로 늘렸다(정산·영수증·숙소·이미지 저장·다녀온 곳 지도 추가).
- 캡처 위 설명은 번호 점·반투명 강조 상자·번호별 설명 목록으로 코드로 그린다(사용자 요청: 도트·화살표·투명 상자). 자리는 캡처 때 화면 요소를 재서 `guide-marks.ts`로 만든다.
- 2026-10-01 변경(사용자 피드백): 구름이와 번호를 빼고, 캡처가 화면 폭을 채우는 코치마크 방식으로 바꿨다. 회색 덮개에서 설명할 요소만 밝게 뚫고 한 줄 말풍선(11px, 실제 글꼴로 폭을 잼)을 가는 선으로 잇는다. 배치는 `util/spotlight.ts`가 겹침이 가장 적은 자리를 고른다. 휴대폰 높이(390×844)로 2배 해상도로 찍는다. 짧게 찍으면 아래 고정 버튼이 내용 중간에 걸렸다. HTML로 다시 그려 보았으나 실제 화면과 달라 버렸다. 설명 글은 `model/guide.ts`의 spots, 자리는 `guide-marks.ts`의 spot 번호로 잇는다.
- 주소는 `/guide` 대신 `/account/guide`다(계정 라우트의 로그인 확인을 그대로 쓴다).
- 캡처는 jpg(12장 약 350KB)다. 테스트 데이터의 '테스트용' 표시는 찍기 직전 화면 글자에서만 지운다.

## 5. 범위에 넣지 않는 것

- 기능별 말풍선 툴팁(화면 위에 겹쳐 뜨는 안내).
- 3D 구름이·움직이는 구름이.
- 영상 안내.
