# AI 없이 사용하는 채팅 명령

여행 상세의 채팅에서 사용한다. 조회·계산은 바로 답하고, 변경은 확인 카드에서 **반영하기**를 눌러 적용한다. AI 호출 횟수를 사용하지 않는다. 저장된 이름·날짜·분류·금액만 사용하며 외부 장소 정보는 만들지 않는다.

| 작업 | 입력 예시 |
| --- | --- |
| 미배치 전체 배정 | 미배치 장소 모두 1일차로 배정해 |
| 특정 장소 이동 | 오죽헌 2일차로 옮겨 / 오죽헌 2일차로 |
| 하루 전체 이동 | 1일차 장소 전부 2일차로 옮겨 |
| 여러 장소 이동 | 오죽헌이랑 경포대 2일차로 옮겨 |
| 분류별 배정 | 미배치 중 카페만 2일차로 옮겨 |
| 미배치 복원 | 오죽헌 미배치로 옮겨 |
| 순서 | 오죽헌 맨 앞으로 / 오죽헌이랑 경포대 순서 바꿔 |
| 체류시간 | 오죽헌 체류시간 1시간 30분으로 바꿔 / 카페 체류시간 전부 40분으로 |
| 고정 시각 | 오죽헌 오후 2시로 고정해 / 1일차 방문 시각 고정 전부 풀어 |
| 메모 | 오죽헌 메모에 입장권 확인 추가해 / 오죽헌 메모를 오전 방문으로 바꿔 |
| 제외·복원 | 경포대 이번 일정에서 제외해 / 경포대 다시 포함해 |
| 삭제 | 오죽헌 삭제해 / 1일차 장소 모두 삭제해 |
| 제목 | 여행 이름을 강릉 주말여행으로 바꿔 |
| 날짜 이동 | 여행 전체를 하루 뒤로 미뤄 / 여행 전체를 2일 앞으로 당겨 |
| 날짜 변경 | 여행 시작일을 2026-10-01로 바꿔 / 여행 종료일을 2026-10-03으로 바꿔 |
| 날짜 미정 | 여행 날짜 미정으로 해줘 |
| 되돌리기 | 방금 변경 되돌려 |
| 일정·장소 조회 | 2일차 일정 보여줘 / 일정에 넣은 카페 찾아줘 / 오죽헌 몇 일차에 넣었지? |
| 누락 정보 | 날짜 없는 장소 알려줘 / 체류시간 안 정한 장소 보여줘 / 숙소 안 정한 날짜 알려줘 |
| 합계 | 체류시간 합계 알려줘 / 장소 예상 비용 합계 알려줘 |
| 점검 | 중복 장소 찾아줘 / 방문 시간이 겹치는 일정 찾아줘 |
| 경비 추가 | 점심값 2만원 추가해 / 2026-10-01 점심값 20000원 기록해 |
| 경비 수정·삭제 | 점심값 25000원으로 수정해 / 지출 점심값 삭제해 |
| 예산 | 예산 30만원으로 설정해 / 예산 얼마나 남았어? |
| 지출 조회 | 지출 합계 알려줘 / 오늘 얼마 썼어? / 2026-10-01 지출 합계 알려줘 |
| 균등 계산 | 총비용 3명이 똑같이 나누면? |
| 화면 이동 | 여행 경비 열어줘 / 2일차 지도 열어줘 (일정 화면 링크 제공) |
| 내보내기 | 일정 텍스트로 복사해줘 (복사 버튼 제공) |
| 도움말 | 명령어 알려줘 |

## 범위와 제약

- 날짜 배정은 일차·첫날·오늘·내일·YYYY-MM-DD를 지원한다. 오늘은 기기 로컬 날짜다. 날짜 변경은 ISO 형식을 사용한다.
- 정확한 저장 이름으로 대상을 지정한다. 동명이거나 이름이 겹치면 일정 화면에서 선택한다. “이 장소”와 제외 조건·복합 작업은 추측하지 않는다. “장소 삭제해”만으로 전체를 삭제하지 않는다.
- 카페는 저장된 `break`, 식사는 `meal` 분류다. AI로 장소 업종을 추정하지 않는다.
- 순서 교환은 같은 날짜의 장소끼리 가능하다. 미배치로 옮기면 기존 미배치 뒤에 붙인다.
- 전체 여행 날짜 이동은 숙박 날짜도 함께 옮긴다. 기간 변경으로 저장된 장소·숙박이 기간 밖에 남으면 거절한다. 숙박이 있는 여행의 날짜 미정 전환은 숙박을 먼저 정리해야 한다.
- 체류시간 합계는 이동시간을 제외한다. 미정 항목 수를 함께 표시한다. 시간 충돌은 저장된 고정 시각·체류시간만 비교한다. 중복은 같은 외부 장소 ID 또는 이름·주소 조합의 후보다.
- 경비 추가는 결제자가 한 명일 때 그 결제자·분류 기타로 기록한다. 여러 참여자는 기존 가계부 화면에서 결제자·분담을 선택한다. 금액 수정은 개인 지출 또는 단독 분담일 때 가능하다. 동명 지출과 “방금 쓴” 같은 불명확한 대상을 자동 수정하지 않는다.
- 지출은 실제 기록 날짜를 사용하므로 여행 기간 밖의 선결제도 가능하다. 균등 계산은 실제 정산·송금 기록을 변경하지 않는다.
- 확인 이후 여행 또는 관련 가계부가 달라지면 이전 초안을 적용하지 않는다. 되돌리기도 이후 변경을 덮어쓰지 않는다.
- 추천·취향 판단은 기존 AI 흐름을 유지한다. 날씨·실제 이동시간·외부 장소 검색의 새 채팅 연결은 이번 내부 명령 범위에 포함하지 않는다.
