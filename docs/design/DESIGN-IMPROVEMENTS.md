## 점검 범위와 한계

- 브라우저 직접 확인: `/login`, `/install`, `/lab`(390px·데스크톱). 로그인 뒤 화면은 사용법 캡처(`app/public/guide/*.jpg`)와 소스로 검토했다. 캡처는 현재 작업 트리보다 오래됐을 수 있다.
- 탐지기는 파서 모듈 없이 정규식 모드로 실행되었다. CLI 지적 5건(`layout-transition` 3, `border-accent-on-rounded` 2)은 모두 오탐으로 판단했다.
- Nielsen 휴리스틱 합계 27/40. 낮은 항목: 일관성과 표준 2, 유연성과 효율 2, 미적·최소 디자인 2.

## 반드시 고칠 사항

### P1

1. **선택 상태 표현 통일**: 날짜 탭은 남색 그라데이션(`trip-detail.html:102`), 지도 분류 칩은 딥 블루(`map-explore.html:86`), 평점 칩·장소 종류는 검정(`map-explore.html:102`, `stop-form.html:21`)이다. DESIGN.md의 "딥 블루 = 현재 선택"과 어긋나고, 검정이 주 동작인지 선택인지 알 수 없다. → `aria-pressed` 기반 공통 칩/세그먼트 하나로 묶고 실험실에 예제를 둔다.
4. **지도에서 담기 상단 과부하**: 검색·날짜·분류 4·평점 3이 지도 높이의 약 30%를 가리고, 정보판이 열리면 선택 마커가 잘린다. → 평점은 "필터" 팝오버로 접고, 정보판이 열리면 선택 마커를 보이는 영역으로 옮긴다.
5. **로그인·초대·설치 화면 상단 대비**: 탑승권 그라데이션(`login.html:29`, `invite.html:36`, `install.html:37`) 위 12–13px 흰 글자가 #3b6fef에서 4.46:1이다. 보라(`stay-ink`)로 끝나는 그라데이션은 흔한 AI 팔레트로도 잡혔다. → 시작 색을 한 단계 진하게 하거나 단색 딥 블루로 바꾼다.

### P2

6. **한 화면에 주 버튼 두 개**: "가까운 순 정렬"이 `variant="primary"`라 하단 "일정 추가"와 시선이 갈린다(`trip-detail.html` 약 250행). → 보조 버튼으로 낮춘다.
8. **가계부 요약 막대 오해**: 분류 비율 막대(`expenses.html:48-62`)가 "예상/실제" 아래 전체 폭으로 있어 분류가 하나면 예산을 다 쓴 것처럼 읽힌다. → "실제 지출" 아래로 옮기고 라벨을 붙이거나 분류가 하나일 때 숨긴다.
9. **동작 이름·진입점 통일**: 장소 추가 폼에 "찾기"(링크)와 "검색"(키워드)이 함께 있고, 숙소 탭 하단 버튼이 "일정 추가"다(`trip-detail.html:906`). → 동사는 "검색"으로 통일하고 하단 버튼은 탭에 맞춰 바꾼다.
10. **정보 구조·발견성**: 고정 내비게이션이 없고 통계는 목록 배너로만, 사용법·공지·문의·알림은 아바타 → 내 정보 안(`account.html:129-203`)에만 있다. 여행 중 "오늘 일정"으로 바로 가는 길이 없다. → 목록 상단에 진행 중·다음 여행 카드를 둔다.
11. **통계 지도 조작 과다**: 떠 있는 버튼 6개와 상단 바·본문 제목 이중 표시. → 확대·축소는 핀치에 맡기고 초기화만 남기며 본문 제목을 뺀다.

### P3

12. **보조 글자 대비**: D-day 라벨 `text-ink-3` on `bg-ground-2`(`trip-list.html:172`) 4.24:1, `--color-hint` 바탕 위 4.36:1, 실험실 4.2–4.4:1. → ink-3을 #646a75 정도로 진하게 하고 theme.css 대비 검사에 바탕 조합을 추가한다.
13. **공지 마크업**: `notices.html`에서 본문 전체가 `<summary>` 안에 있어 낭독기가 전문을 버튼 이름으로 읽고, 안 읽음 점은 역할 없는 `aria-label` span이다. → summary에는 제목·날짜만 두고 점에는 `sr-only` 문구를 둔다.
14. **작은 링크**: 로그인 하단 "이용약관"(41x14)·"개인정보 처리방침"(86x14), 실험실 목차 링크 높이 22px.

## 사소한 관찰

- 여행 상세는 불러오는 동안 본문이 비어 있다(`trip-detail.html:1-6`). 느린 망에서는 빈 화면처럼 보인다.
- 메뉴 배경 버튼에 인라인 `style`이 Tailwind 클래스와 중복된다.
- 실험실에 선택 칩·날짜 탭·activity/shopping/other 배지 예제가 없다.
- 로그인 소개 3가지에 "AI 일정 짜기"가 빠져 있다.
- 영수증 화면 하단 버튼 3개 중 "닫기"가 전체 폭이다. 상단 닫기로 옮긴다.
- 챗봇 추천 칩이 가로로 잘리는데 끝 페이드가 없어 깨진 것처럼 보인다.
- 가계부 머리말 "강릉시·속초시 여행 ·" 뒤가 비어 가운뎃점만 남은 캡처가 있다(원인 미확인).

## 미확인

- 로그인 뒤 화면(목록·상세·지도·통계)은 실제 브라우저 측정을 하지 못했다.
- 일정 추가 메뉴(`details` 안 `role="menu"`)의 방향키 조작 지원 여부는 확인하지 않았다.
