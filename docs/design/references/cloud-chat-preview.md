# 구름이 챗봇 확정 시안과 적용 기록

## 메시지 말풍선 후속 수정

사용자 승인에 따라 사용자·구름이 말풍선 모서리를 18px로 통일하고 구름이 답변·응답 대기에만 왼쪽의 작은 꼬리를 추가했다. `chat-thread.css`에서 관리하며 독립 미리보기에도 동일한 형태를 반영했다. 기획안 35절·DESIGN.md·OpenSpec 제안/설계/요구사항/작업을 함께 갱신했다.

검증: test 구성 컴파일과 `cloud-mascot.spec.ts` 데스크톱·360px E2E 2개 통과. 실제 모바일 앱 캡처에서 꼬리가 아바타와 겹치지 않는 것을 확인했다. 미리보기 390px 가로 넘침 없음·이미지 누락 0개, 표정 전환과 버튼 동작 통과. Impeccable 정적 검사 0건. 아래의 전체 29개 E2E 및 프로덕션 빌드 기록은 이전 구름이 적용 시점의 검증이다.

## 구름이 적용

사용자가 선택한 `companion-cloud-sorry-v1.png`와 `companion-cloud-sleepy-v1.png`를 현재 채팅의 밝은 배경·파란 사용자 말풍선·흰 답변 말풍선에 맞춰 비교했다.

- 미리보기: `output/draw/cloud-chat-preview.html`
- 데스크톱 캡처: `output/draw/cloud-chat-preview.png`
- 모바일 캡처: `output/draw/cloud-chat-preview-mobile.png`
- 상호작용: 표정 선택 버튼으로 아바타 교체. 대기 버튼을 누르면 작은 미소로 돌아오며 채팅 시안으로 이동한다.
- 사용자 피드백 반영: 몸통이 잘린 듯 보이는 얼굴 크롭을 제거했다. 대화는 48px, 헤더는 56px 전신을 표시한다.
- 플로팅 버튼: 파란 알약형 버튼에 구름이와 ‘AI 채팅’ 라벨을 배치했다. 사용자 피드백에 따라 중복되는 말풍선 아이콘은 제거했다. 크기를 줄여 달라는 추가 피드백에 따라 높이는 56px에서 44px, 구름이 이미지 상자는 76px에서 56px, 글자는 15px에서 13px로 줄였다. 구름이는 버튼 위로 살짝 올라오며 전신을 유지한다.
- 확정: 대화·추천 결과·응답 준비에는 작은 미소, 대기 진입 버튼에는 졸린 전신을 사용한다. 두 PNG는 내장 image_gen으로 제작했다.
- 검증: 수정 후 Playwright에서 표정 전환 및 대기 버튼 동작 확인, 이미지 누락 0개, 390px 화면 가로 넘침 없음. 데스크톱·모바일 캡처에서 전신과 버튼 라벨을 육안 확인했다. Impeccable 정적 검사 결과 0건.
- 앱 적용: `CompanionFace`의 크롭을 제거하고 두 이미지로 연결했다. 목록과 상세의 진입점을 작은 파란 ‘AI 채팅’ 버튼으로 교체했으며 전체 채팅·상세 시트에 56px 헤더 캐릭터를 추가했다. 기존 추천·장소 검증·저장 흐름은 유지한다.
- 문서: 기획안 35절, DESIGN.md와 OpenSpec `apply-cloud-chat-mascot`에 승인된 규칙을 기록했다. 위 HTML은 예시 대화가 있는 독립 시안으로 보존한다.
- 정리: 앱 이미지 19장, 개별 생성 MD 10개, 낡은 비교 HTML·렌더 스크립트와 비교 전용 테스트를 삭제했다. 앱에는 선택한 PNG 2장만 남겼다. 사용자 `.codex/generated_images`의 원본은 변경하지 않았다.
- 앱 검증: `npm run build` 성공, `npm run lint`의 기능 경계·순환 의존 검사 164개 모듈 통과. 별도 4300 테스트 앱에서 `npx playwright test e2e/travel-chat.spec.ts e2e/cloud-mascot.spec.ts` 29개 통과·1개 의도적 제외(모바일 전용 검사의 데스크톱 실행). 목록·상세 버튼의 44px 높이, 150px 미만 너비, 56px 캐릭터, 답변 48px 전신 이미지 로드, 헤더 56px, 360px 가로 넘침 없음 및 일정 추가 바와의 비중첩을 확인했다. 기존 채팅 테스트의 지역 입력은 현재 검색 결과 이름인 ‘강릉시’로 정정했다.
- 실제 앱 캡처: `output/playwright/cloud-mobile-360-list.png`, `cloud-mobile-360-chat.png`, `cloud-mobile-360-detail.png`, `cloud-mobile-360-sheet.png` 및 같은 이름의 `cloud-desktop-*` 4장. 최종 화면을 육안 확인했다.
- 남은 경고: 로그인 화면 미사용 import 2건, 초기 번들 735.71kB/경고 기준 500kB. 이번 캐릭터 적용 범위 밖으로 유지했다. Impeccable 정적 검사의 이미지 경고 1건은 Angular `[src]` 바인딩을 인식하지 못한 결과이며 실제 브라우저 로드를 확인했다.
