미배치

휴대폰에서는 아래에서 시트가 올라와 엄지로 고르기 쉽고 항목이 커서 덜 잘못 누른다. PC는 A처럼 상자 아래. 한 번 더 화면이 바뀌는 느낌이 있다.

바뀌는 점 정리
  • 아이폰·사파리에서 기기 휠 대신 앱 모양 목록이 뜬다(가장 큰 차이).
  • 크롬은 겉모습이 거의 같다. 대신 크롬 버전마다 다르게 동작하던 꾸민 목록(오늘 고친 '눌러도 안 골라짐' 같은 문제)에 기대지 않는다.
  • 공통 컴포넌트 하나(예: app-select)로 바꾸고 기존 선택 상자 전부를 옮긴다. 키보드·화면 읽기·바깥 누르면 닫기를 직접 맞춰야 해 작업량이 가장 큰 부분이다.
  • 큰 지도의 1일차 선택은 칩 줄에 맞춘 남색 알약이라 이번 통일에서 뺀다(요청대로).
