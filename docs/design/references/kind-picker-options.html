종류 선택 버튼 색 비교

장소 추가·편집의 '종류'에서 고른 버튼 색만 바꿔 본다. 아래 작은 줄은 같은 앱의 다른 선택(큰 지도 분류 칩)이다. 고른 것은 '식사'.

지금 현재

고른 버튼만 검정에 가까운 짙은 색. 앱의 다른 선택(파랑)과 따로 놀고 무겁다.

A 파랑 채움

분류 칩·주 버튼과 같은 파랑. 앱 전체 '고름 = 파랑'으로 맞는다. 저장 버튼과 같은 색이라 화면에 파랑이 많아진다.

B 연파랑 + 파랑 테두리 추천

선택 목록의 고른 항목과 같은 연파랑. 고른 것이 분명하면서 가볍고, 아래 저장 버튼(진한 파랑)과 겹치지 않는다.

C 종류마다 그 분류 색

여행 상세의 분류 배지 색(식사=초록, 카페=청록…)을 쓴다. 고른 종류가 일정에서 어떤 색으로 보일지 미리 알 수 있지만 고를 때마다 색이 바뀐다.
