# 경계 데이터

통계 지도가 읽는 GeoJSON을 둔다.

## 지금 들어 있는 것

`korea-municipalities-2026.geo.json` 하나이며 **2026-07-01 기준 시·군·구 경계** 230개다. `/stats`의 3D 지도가 이 파일만 읽는다.

속성은 다음과 같다.

| 키 | 뜻 | 예 |
| --- | --- | --- |
| `cd` | 지역 코드. 시·도 번호와 이름을 붙인다 | `12_여수시` |
| `nm` | 지역 이름 | `여수시` |
| `sido` | 시·도 번호 | `12` |
| `sidonm` | 시·도 이름 | `전남광주통합특별시` |

`cd`가 집계와 지도가 공유하는 키다. 같은 이름이 여러 시·도에 있어도(`중구`는 5곳) 번호가 달라 섞이지 않는다.

## 원본과 만드는 법

- 원본: https://github.com/vuski/admdongkor 의 `ver20260701/HangJeongDong_ver20260701.geojson`
- 기준: **2026-07-01**. 광주광역시와 전라남도가 전남광주통합특별시로 통합된 뒤의 행정구역이다. 시·도는 16개다.
- 라이선스: CC BY 4.0. SGIS(통계청) 출처표시 의무를 승계한다.
- 원본은 행정동 3,558개짜리 33MB라 커밋하지 않는다. 받아서 아래 명령으로 줄인다.

```bash
node scripts/build-municipalities.mjs <받은 원본.geojson>
```

변환은 두 가지를 한다.

1. **같은 시·군·구의 행정동을 하나로 녹인다.** 수원·성남·창원처럼 일반구가 있는 시 13개는 구를 상위 시로 합쳐 `수원시` 하나로 만든다. 사용자는 "수원 다녀왔다"라고 하지 "수원 권선구"라고 하지 않는다. 반면 서울·부산의 자치구와 통합시의 옛 광주 자치구는 생활권이 뚜렷해 그대로 둔다. 256개가 230개가 되는 까닭이다.
2. **해안선을 줄인다.** `-simplify 8%`이며 이보다 줄이면 해안가와 섬의 좌표 판정이 실패한다. 실제 장소 좌표 9곳(화엄사·함평·광주 동구·여수·서울 종로·수원 팔달·성남 분당·창원 의창·제주시)으로 확인했다.

## 다른 출처를 쓸 때

| 출처 | 내용 | 조건 |

출처를 바꾸면 라이선스 표기와 이 문서를 함께 고친다. 좌표를 임의로 만들지 않는다.

## 용량

원본이 수십 MB라 번들에 넣지 않고 이 폴더에 두며, 지도 화면에 들어올 때만 받는다. 지금 파일은 594KB다. 지도는 11km 격자로 뭉개 그리므로 원본의 정밀도를 다 쓰지 않는다.

## 지난 기록

- 2026-09-19: 화면 확인용 사각형 fixture 두 개(`skorea-provinces.geo.json`, `skorea-municipalities.geo.json`)를 실제 경계로 대체하며 삭제했다.
